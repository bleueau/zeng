# 应用模式：搭讪与开场问题

> **用途：** 当用户提出「不敢搭讪/搭讪焦虑/搭讪被拒/搭讪后对方不理/不知道怎么开场」等搭讪与开场相关问题时，按此模板分析。

---

## 需要收集的信息

1. **搭讪场景：** 街头/商场/咖啡店/酒吧/校园？白天还是晚上？
2. **自身经验：** 搭讪经验水平（新手/有一些经验/老手）？最近搭讪频率？
3. **具体过程：** 怎么开场的？对方的第一反应是什么？对话持续了多久？有没有加到微信？
4. **心理状态：** 搭讪前的心理状态（紧张/焦虑/放松/兴奋）？搭讪中的感受？
5. **后续：** 加了微信后的互动情况

## 判断路径

```
搭讪案例
    │
    ├─ 不敢搭讪/搭讪焦虑？
    │   └─ 是 → 检查：是否认为自己是在「骚扰」对方？（E0323）
    │         检查：是否放大了被拒绝的后果？（E0244）
    │         检查：是否有「不配」的底层信念？
    │         → 进入「搭讪焦虑」处理路径
    │
    ├─ 搭讪被拒？
    │   └─ 是 → 检查：拒绝不等于人格否定（E0244）
    │         检查：是现场表现问题还是展示面问题？（E0391）
    │         检查：有没有保持一致性？被拒后状态是否崩塌？（E0569）
    │         → 进入「被拒处理」处理路径
    │
    ├─ 搭讪后对方不回复？
    │   └─ 是 → 检查：现场表现 vs 朋友圈展示面（E0391）
    │         检查：是否现场让对方「上钩」了？（E0638）
    │         检查：后续消息的时机和内容
    │         → 进入「加微信后无回应」处理路径
    │
    └─ 不知道怎么开场？
        └─ 是 → 检查：是否「放得开」？（E0092）
              检查：是否过度准备话术？（E0192）
              检查：是否在追求「丝滑」？（E0482）
              → 进入「开场方法」处理路径
```

## 注意边界

- Mikey体系认为：搭讪如果连放都放不开，那就不要玩了——放得开是最基本的要求（E0092）
- Mikey体系认为：搭讪本来就是一个尴尬的行为，没必要追求做得丝滑（E0482）
- Mikey体系认为：一个陌生人没有任何资格否定你的人格（E0244, E0632）
- Mikey体系认为：搭讪没有固定话术——见招拆招这个东西不重要（E0192）
- Mikey体系认为：搭讪很重要的是搭讪是一个很酷的技能一定要去练习（E0243）
- Mikey体系认为：搭讪焦虑的根源在于自我价值感低，认为自己是在骚扰对方（E0323）
- Mikey体系认为：搭讪时多犹豫一秒成功率下降20%（E0472）
- Mikey体系认为：搭讪应以要微信为切入点，拿到微信后再展开聊天（E0253）
- Mikey体系认为：没有勇气一个人搭讪的根本原因是缺乏安全感（E0489）
- Mikey体系认为：很久没搭讪后看到好看的女生会犹豫和焦虑是正常的，连Mikey自己也会（E0492）
- Mikey体系认为：真正的搭讪与骚扰/犯罪有本质区别（E0493, E0603）
- **边界：** Mikey体系明确指出，模仿打压迟到女性的行为需要满足特定的前置条件（你在关系中处于高位且有强行为线索），否则效果会适得其反（E0164）
