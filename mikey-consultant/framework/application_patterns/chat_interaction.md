# 应用模式：聊天互动问题

> **用途：** 当用户提出「聊天变冷了/不知道怎么回/对方不回消息/聊不下去」等聊天互动问题时，按此模板分析。

---

## 需要收集的信息

在分析聊天互动问题前，需要先收集：

1. **关系阶段：** 陌生/熟悉/暧昧/亲密/长期？（见reasoning_process.md Step 1）
2. **聊天记录：** 最近3-5轮对话（越多越准确）
3. **互动历史：** 认识多久？见过面吗？谁先加谁？
4. **关键事件：** 是否有特殊的转折点（某句话后对方突然变冷等）
5. **自身状态：** 描述自己在聊天时的心理状态（焦虑/放松/无所谓等）

## 判断路径

```
聊天案例
    │
    ├─ 对方从不主动发消息？
    │   └─ 是 → 无窗口，在吊你（E0378）
    │         → 进入「无窗口」处理路径
    │
    ├─ 聊天从热变冷？
    │   └─ 是 → 检查需求感暴露（P03）、吸引力（P10）、一致性断裂（P04）
    │         → 进入「降温」处理路径
    │
    ├─ 不知道回什么？
    │   └─ 是 → 可能有心态问题（P09，执着于结果导致紧张）
    │         → 进入「状态调整」处理路径
    │
    └─ 对方回复但很敷衍？
        └─ 是 → 检查吸引是否存在（DM02）、聊天是否追着对方反应（E0204）
              → 进入「吸引不足」处理路径
```

| 问题路径 | 优先调用原则 |
|----------|-------------|

| 降温 | P03(需求感), P10(吸引先于技术), P04(一致性) |
| 状态调整 | P09(零压力状态), P07(自我价值感) |
| 吸引不足 | P10(吸引先于技术), P02(潜沟通), P01(关系动态) |

## 可调用决策模型

- DM02(吸引力存在性判断)
- DM04(需求感暴露判断)
- DM05(框架位置判断)

## 注意边界

- Mikey体系认为：聊天热度应与对方保持一致，热情过度会暴露需求感（E0509）
- Mikey体系认为：不要自说自话追逐对方的反应（E0204）
- Mikey体系认为：对女性的问题有问必答会慢慢掉进对方的框架（E0246）
- Mikey体系认为：遇到高分正妹上线后不知道聊什么时不能慌，退缩或舔上去都会让号变废号（E0031）
- Mikey体系认为：跟任何人相处都不要什么都说，留点秘密（E0248）
- Mikey体系认为：很多兄弟学了技术用不出来，是因为潜意识在限制（E0514）
- **存在不同观点：** 关于「要不要聊性话题」，Mikey体系一致主张不要刻意聊（E0347），但同时在吸引存在时聊性是调情（E0325）。关键是先判断吸引是否存在。
