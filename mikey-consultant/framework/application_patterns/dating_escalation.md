# 应用模式：约会与升级问题

> **用途：** 当用户提出「约会后对方变冷/约会中升级被拒/不知道怎么升级/约会效果不好」等约会与升级相关问题时，按此模板分析。

---

## 需要收集的信息

1. **约会前状态：** 对方的期待程度？线上互动热度？是否自愿赴约？
2. **约会过程：** 约会场所、时间长度、气氛、聊天内容、是否有冷场
3. **升级记录：** 是否尝试升级？升级方式是什么？对方的反应？
4. **约会后状态：** 约会后对方的回复意愿和态度变化
5. **自身状态：** 约会中自己的心态（放松/紧张/执着于结果）

## 判断路径

```
约会升级案例
    │
    ├─ 约会后对方变冷？
    │   └─ 是 → 检查：是否施压过度？（E0001, E0002）
    │         检查：是否一致性断裂？（前后人设变化）
    │         检查：是否有不当行为？（开黄腔、毛手毛脚）
    │         → 进入「约会后降温」处理路径
    │
    ├─ 约会中升级被拒？
    │   └─ 是 → 检查：是否有情感共振？（E0004）
    │         检查：是否一上来就疯狂升级？（E0003）
    │         检查：窗口是否被误判？（DM01）
    │         → 进入「升级失败」处理路径
    │
    ├─ 不知道如何升级？
    │   └─ 是 → 检查：当前处于什么关系阶段？
    │         检查：对方类型（内向/外向/保守/开放）
    │         → 进入「升级方法」处理路径
    │
    └─ 约会整体效果不好？
        └─ 是 → 检查：是否做了让自己不自在的事？（E0010）
              检查：是否面对面坐像面试？（E0009）
              检查：是否太过执着于结果？（E0017）
              → 进入「约会质量」处理路径
```

## 注意边界

- Mikey体系认为：永远不要施压过度（E0002）
- Mikey体系认为：没有共振直接升级会给女生猥琐的感觉（E0004）
- Mikey体系认为：反感时坐回原点重新判断窗口再升级（E0003）
- Mikey体系认为：让对方下头意味着不会有下一次机会（E0005）
- Mikey体系认为：第一次约会前30分钟特别重要——创造吸引力的黄金窗口（E0718）
- Mikey体系认为：约会时聊得很开心疯狂情绪共振其实不是好事（E0723）
- Mikey体系认为：肢体升级时要大方从容，不能紧张（E0678）
- Mikey体系认为：遇到内向的女生多用眼神和语调而非肢体（E0008）
- Mikey体系认为：约会场所应该由男生选择和控制（E0010, E0105）
- Mikey体系认为：约会时不要面对面坐像面试（E0009）
- Mikey体系认为：针对保守女生需要收着给安全感（E0651）
- Mikey体系认为：不同认知维度的女性同一操作方法可能失效（E0637）
- **存在不同观点：** 关于「约会时应该聊什么」——Mikey体系认为应该大量分享自己的经历和故事（E0058），同时不应害怕冷场、想说话就说不想说就不说（E0105）。两者在不同阶段使用。
