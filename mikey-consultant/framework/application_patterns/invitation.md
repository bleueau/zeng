# 应用模式：邀约问题

> **用途：** 当用户提出「约不出来/一直被推脱/不知道什么时候该约/约了又鸽」等邀约相关问题时，按此模板分析。

---

## 需要收集的信息

1. **互动历史：** 认识多久？怎么认识的（搭讪/社交圈/软件）？见过面吗？
2. **邀约记录：** 邀约了几次？每次的拒绝理由是什么？是否曾成功约出来过？
3. **线上聊天状态：** 聊天频率、对方主动程度、聊天质量
4. **邀约时机：** 邀约时线上聊到什么程度？是否已经建立足够安全感？
5. **自身状态：** 邀约时的语气和心态（自信/紧张/不确定）

## 判断路径

```
邀约案例
    │
    ├─ 从未成功约出来过？
    │   └─ 是 → 检查：是否聊到对方有足够安全感？（E0502）
    │         检查：是否在线上聊太多导致幻想破灭？（E0503）
    │         → 进入「首次邀约失败」处理路径
    │
    ├─ 约出来过但后来约不出来了？
    │   └─ 是 → 检查：上次约会后是否有吸引力流失？
    │         检查：是否上次约会中施压过度？（E0001, E0002）
    │         检查：是否有需求感暴露？（E0194）
    │         → 进入「邀约中断」处理路径
    │
    ├─ 被以「忙」为理由推脱？
    │   └─ 是 → 判断是真忙还是借口（E0312, E0545）
    │         → 进入「推脱判断」处理路径
    │
    └─ 邀约后对方鸽了（临时有事不来）？
        └─ 是 → 检查：是否有明确的契约建立？（E0507）
             检查：对方是否真正重视这次见面？
             → 进入「契约问题」处理路径
```

## 注意边界

- Mikey体系认为：邀约的前提是对方对你这个人的安全感足够，而不是聊到多深入（E0502）
- Mikey体系认为：不应该在网上聊到暧昧再见面，应先以见面为前提（E0503, E0573, E0628）
- Mikey体系认为：微信上只需要聊到双方知道彼此是正常人就可以邀约（E0636）
- Mikey体系认为：邀约确定之后要达成契约——不卑不亢给出你的标准（E0507）
- Mikey体系认为：第一次邀约失败只需要再约一次，看拒绝的真实原因是什么（E0547）
- Mikey体系认为：女人说忙或不方便并不一定是拒绝你，不要玻璃心（E0312）
- Mikey体系认为：女生说平日忙只有假日有空然后假日也说忙——她不想见你（E0545）
- Mikey体系认为：能及时约会一定要及时约会——对方已经上钩了就应该立刻共振（E0667）
- Mikey体系认为：太多女人在网上打嘴炮聊骚但见面行不通，以见面为前提（E0660）
