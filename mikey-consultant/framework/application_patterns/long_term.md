# 应用模式：长期关系问题

> **用途：** 当用户提出「确定关系后对方变冷/长期关系中吸引力流失/不知道如何维持长期吸引/被绿/分手」等长期关系相关问题时，按此模板分析。

---

## 需要收集的信息

1. **关系历史：** 在一起多久？如何认识的？从认识到确定关系的历程
2. **当前状态：** 最近1-3个月的互动质量变化趋势
3. **关键事件：** 是否有触发关系变化的重要事件（吵架/发现秘密/生活变故等）
4. **行为一致性：** 确定关系前后自己的行为是否有明显变化？
5. **可得性程度：** 对方是否觉得已经完全「得到」了你？
6. **双方投入：** 情绪投入、时间投入、精力投入的比例

## 判断路径

```
长期关系案例
    │
    ├─ 确定关系后对方明显变冷？
    │   └─ 是 → 检查：是否一致性断裂？（前后人设变化，E0727）
    │         检查：是否完全被对方「得到」？（E0739）
    │         检查：是否框架沦陷？（开始讨好/迎合，DM05）
    │         → 进入「吸引力流失」处理路径
    │
    ├─ 关系中出现疑似出轨/背叛？
    │   └─ 是 → 检查：是否传递了「出轨就再见」的框架？（E0551）
    │         检查：是否表现出稀缺和讨好？（E0551）
    │         检查：是不满足「慕强条件」导致的？（E0692）
    │         → 进入「关系安全」处理路径
    │
    ├─ 关系中被对方主导/控制？
    │   └─ 是 → 检查：是否不敢表达不同意见？（E0016）
    │         检查：是否边界感模糊？（E0115, E0341）
    │         → 进入「框架沦陷」处理路径
    │
    ├─ 考虑分手/刚分手？
    │   └─ 是 → 检查：问题的根源是什么？
    │         检查：是否自己的吸引力/一致性出了问题？
    │         → 进入「分手决策」处理路径
    │
    └─ 不知道如何维持长期吸引力？
        └─ 是 → 检查：是否保持了一致性？
              检查：是否控制了可得性？
              检查：是否持续提升自身价值？
              → 进入「长期维护」处理路径
```

## 注意边界

- Mikey体系认为：长期关系是对整个人魅力的综合考试，不像是约会只是单独一场（E0318）
- Mikey体系认为：确定关系后吸引力下降的根本原因是失去了保持一致性（E0727）
- Mikey体系认为：长期关系中一定要控制可得性——永远不能让对方觉得完全得到了你（E0739）
- Mikey体系认为：如果在关系中传递「出轨就再见」的框架，对方大概率不会出轨（E0551）
- Mikey体系认为：女性真正喜欢的是她感觉能改变但永远改变不了的男人（E0719）
- Mikey体系认为：对方说希望你改好但你千万不要改——改的那一刻吸引力就开始降低（E0733）
- Mikey体系认为：长期关系最佳状态是对方对你充满敬畏感而非过度甜蜜——过犹不及（E0750）
- Mikey体系认为：想发展长期关系永远先以短期关系为基础（E0692）
- Mikey体系认为：女性说希望你改好但你改了→吸引力降低，你开始被驯化了（E0733）
- Mikey体系认为：分手后不要沉溺情绪，应分析问题、找根源、解决，然后找下一个更好的（E0649, E0707）
- Mikey体系认为：分手后找的下一个女朋友一定要比上一个更好看（E0444）
- Mikey体系认为：找到真正爱的人后不必逼自己继续转盘子（E0421）
- **存在不同观点或适用条件：** 「女性没有安全感是吸引力的正面指标」（E0528）与「邀约的前提是安全感」（E0502）看似矛盾——Mikey体系认为两者在不同维度上共存：关系动态层面的「抓不住」和基本信任层面的「安全感」是不同概念
