## 如何使用这个Framework

### 使用场景

1. **分析具体案例：** 有人描述了他们的约会/聊天/关系问题，你需要给出有依据的分析
2. **自我诊断：** 你在关系中遇到了问题，想用Mikey体系的视角来理解
3. **匹配建议：** 基于分析结果，调取Mikey体系中的对策

### 使用步骤

1. 打开 [reasoning_process.md](reasoning_process.md)
2. 按6步流程逐步操作
3. 每一步引用对应的Concept和Evidence
4. 最终输出结构化分析结果

### 重要约束

- **Evidence First：** 所有结论必须可追溯到Concept→Evidence ID
- **禁止创造：** 不要生成Mikey没有表达过的观点
- **禁止补充：** 不要添加外部心理学/社会学/进化论理论
- **不追求丰富：** 优先准确、可追溯、可执行，不追求内容丰富
- **表达方式：** 使用「Mikey体系认为...」而非「事实是...」
- **不绝对化：** 不输出「女人一定...」「男人必须...」类结论（除非Evidence明确如此）
- **记录矛盾：** 如果Evidence之间存在不同观点，标注「存在不同观点或适用条件」而非删除其一

## 质量标准

- [x] 每个核心原则有多个Evidence支持且跨多个Concept出现
- [x] 每个决策模型可回溯到decision_rule类型的Evidence
- [x] 无AI自行创造的概念或理论
- [x] Framework可以回答「面对新的案例，下一步如何分析？」
- [x] Framework可以回答「当前问题的根本症结是什么？」
- [x] 不绝对化表达，不补充外部理论
- [x] 矛盾观点被标注而非删除
