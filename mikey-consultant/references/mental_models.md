## 1. 设计理念

### 1.1 为什么需要 Mental Model

Phase 0 审计报告的核心结论：**Mikey 是一个 Mental Model，不是一个 Rule System。**

10 条原则和 8 个决策模型告诉 AI "Mikey 知道什么"，但没有告诉 AI "Mikey 怎么思考"。Mental Model 填补这个空缺——它构建的是 Mikey 脑中的**关系世界运转模型**：
- 不是 "需求感高不好"（这是原则），而是 "需求感暴露 → 对方感知已拿捏 → 对方停止投入 → 吸引力下降"（这是因果链）
- 不是 "要保持一致性"（这是规则），而是 "一致性断裂 → 信任崩塌 → 吸引力流失 → 对方测试加剧"（这是因果链）

### 1.2 设计约束

1. **因果方向明确**——是 A→B 还是 B→A 还是 A↔B？
2. **中间机制可解释**——不是说 "A 导致 B"，而是说 "A 通过什么机制导致 B"
3. **只从 Evidence 提取**——不创造 Mikey 没表达过的因果链
4. **适用边界标注**——每个模型在什么条件下成立、失效
5. **模型互联**——8 个模型是一个因果网，不是 8 个孤岛
6. **控制规模**——每个模型 ≤500 字，总计 ≤4000 字

### 1.3 核心因果变量

Mikey 体系中的 6 个核心因果变量（不是独立的，是相互耦合的）：

| 变量 | 含义 | 变化方向 | 与谁耦合 |
|------|------|---------|---------|
| **吸引力** | 对方对你的兴趣/好感 | ↑ 升 / ↓ 降 | 需求感、框架、一致性、投资 |
| **需求感** | 你暴露出的"需要对方"程度 | ↑ 暴露 / ↓ 隐藏 | 吸引力、框架 |
| **框架位置** | 关系中的相对权力地位 | 上位 / 平衡 / 下位 | 边界感、需求感、投资 |
| **投资差距** | 双方投入的不对称程度 | 你多/平衡/对方多 | 需求感、框架、吸引力 |
| **窗口状态** | 升级关系的时机存在性 | 开 / 关 / 模糊 | 吸引力、时机 |
| **一致性** | 行为前后的一致程度 | 一致 / 断裂 | 吸引力、框架 |

## M1：吸引力动态模型

**核心因果链：**

```
强行为线索投射 → [社会地位感知机制] → 对方感知"上位者" →
吸引力建立 → 对方投入 → 吸引力强化（正反馈）
                                      ↓
弱行为线索投射 → [社会地位感知机制] → 对方感知"下位者" →
吸引力流失 → 对方停止投入 → 吸引力进一步流失（负反馈）
```

**变量关系：**

- **正反馈：** 吸引力↑ → 对方投入↑ → 你自然放松（P09）→ 强行为线索↑ → 吸引力↑
- **负反馈：** 吸引力↓ → 你焦虑追逐↑ → 需求感暴露↑ → 吸引力↓↓
- **临界点：** 当对方感知"已拿捏"时，吸引力进入不可逆下降通道（P03, DM04）

**中间机制：**

吸引力不是通过"展示"建立的——它是通过**行为线索传递的社会地位信号**建立的。女性通过潜沟通（P02）判断男性价值：姿态、节奏、是否紧张、是否讨好。外在数值（财富/外貌）只提供"坐下喝杯咖啡"的资格，不创造吸引（E0075, E0080）。吸引的本质是"对方感觉你是上位者"（P01）。

**Evidence 支撑：**

P01（关系动态决定吸引力）、P02（潜沟通传递核心信息）、P10（吸引先于一切技术）、DM02（吸引力存在性判断）  
E0075, E0080, E0301, E0316, E0322, E0521, E0575

**适用边界：**

- **成立条件：** 对方能够感知到行为线索（面对面的动态阅读比纯线上更准确）；对方尚未形成"这个人不行"的固化判断
- **失效条件：** 对方已形成不可逆的负面判断（过了临界点）；纯线上互动中信号衰减严重；对方价值观/偏好与 Mikey 体系的"慕强"假设不匹配
- **注意：** 吸引力不是二元变量——它是一个光谱。不存在"有"或"没有"的绝对二分

**与其他 Model 的关系：**

- M1 是 M4（投资循环）的上游——吸引建立后才会有对方的主动投资
- M1 被 M2（需求感传导）反向抑制——需求感暴露会直接杀吸引力
- M1 是 M7（升级推进）的前提——没有吸引，升级必定失败
- M1 受 M6（一致性维持）保护——一致性断裂会侵蚀已建立的吸引力

## M2：需求感传导模型

**核心因果链：**

```
用户行为：高频主动/追逐/讨好
  → [潜沟通解码机制] 对方读取："这个人没有其他选择" / "已被我拿捏"
  → 对方停止投入（因为不需要争取）
  → 投资差距扩大（你多她少）
  → 框架位置下移（你变成下位）
  → 吸引力下降 → [自证预言] 用户感知吸引力下降 → 更焦虑 → 更多追逐
```

**变量关系：**

- **负反馈循环（破坏性）：** 需求感暴露↑ → 吸引力↓ → 用户焦虑↑ → 更多追逐↑ → 需求感暴露↑↑（恶性加速）
- **临界点：** 对方形成"已拿捏"判断 → 此后用户做任何事都被解读为"他在讨好我"
- **逆转关键：** 打破追逐循环 → 停止暴露 → 对方重新产生不确定性

**中间机制：**

需求感不是通过"说了什么"传递的（P02），而是通过**行为线索**传递的。当你发 5 条对方回 1 条、当你在对方不回应时继续发、当你聊天热度明显高于对方——你不是在"表达喜欢"，你是在传递"我比你更需要这段关系"。对方的潜意识解码是："他有其他选择吗？如果有，他不会这样。"（P03, DM04）稀缺性效应的反面：越是可得，越不被珍惜。

**Evidence 支撑：**

P03（需求感是吸引力杀手）、DM04（需求感暴露判断）、P09（零压力状态最佳）  
E0194, E0520, E0534, E0737, E0509

**适用边界：**

- **成立条件：** 在吸引未建立或脆弱时，需求感暴露的杀伤力最大
- **弱化条件：** 在已有强吸引 + 对方也暴露需求感（双向投入时），适度需求感不会立刻杀吸引——但长期仍需控制
- **失效条件：** 如果吸引从未存在，则"降低需求感"只会改变行为线索，不会创造吸引——必须先建吸引（M1）
- **文化差异：** 不同文化对"主动追求"的容忍度不同，Mikey 体系基于当代都市约会文化

**与其他 Model 的关系：**

- M2 ↔ M3（框架动态）：需求感暴露导致框架下移；框架下移加速需求感暴露（互为因果）
- M2 → M4（投资循环）：需求感暴露 → 投资差距扩大 → 单向投资的恶性循环
- M2 → M1（吸引力动态）：需求感是吸引力杀手——它是 M1 负反馈循环的核心加速器
- M2 ↔ M8（关系衰减）：需求感暴露是长期关系中吸引力衰减的主要驱动因

## M3：框架动态模型

**核心因果链：**

```
框架建立：丑话前置/边界表达/从容不迫 → [社会地位感知] → 对方感知"这个人有标准"
  ↓
框架测试（废测）：对方试探边界（迟到/爽约/质疑/要求你改变）
  ├── 测试通过（不讨好/不解释/不迎合）→ 框架强化 → 吸引力↑（M1）
  └── 测试失败（解释/讨好/改变自己）→ 框架弱化 → 对方继续测试 →
     框架进一步弱化 → 最终沦陷（"你被驯化了"）
```

**变量关系：**

- **正反馈（强化）：** 框架强↑ → 对方尊重边界↑ → 你更从容↑ → 框架更强↑
- **负反馈（侵蚀）：** 框架弱↓ → 对方测试加剧↓ → 你迎合↓ → 框架更弱↓↓
- **不可逆阈值：** 框架沦陷后，对方已形成"他可以被我改变"的判断——修复需要远大于维持的成本

**中间机制：**

框架的本质是"谁制定互动的规则"（P01, DM05）。它不是通过说"我有框架"建立的，而是通过：不解释（反解释，E0737）、丑话前置（E0544, E0546）、敢于拒绝（P08）、不在对方测试时慌（废测回应）来传递的。每一次你让步，你不是在"对她好"，你是在告诉她"你的规则比我的规则重要"——这会触发对方的测试本能：她会继续试探，看你还有什么可以妥协。

**Evidence 支撑：**

P01（关系动态决定吸引力）、P08（边界感维持框架）、DM05（框架位置判断）  
E0016, E0234, E0535, E0544, E0546, E0683, E0737, E0084

**适用边界：**

- **成立条件：** 框架博弈发生在吸引已建立的互动中。没有吸引时，对方根本不在意你的框架
- **失效条件：** 如果对方从未进入关系/互动，则框架无从建立
- **警惕：** "有冲突能力但选择不冲突"（E0683）和"被迫服软"表现可能相似但本质完全不同——前者是选择，后者是沦陷
- **性别差异：** Mikey 体系主要描述男性框架——女性框架博弈的机制对称但信号类型不同

**与其他 Model 的关系：**

- M3 ↔ M2（需求感传导）：框架沦陷和需求感暴露互为加速器
- M3 → M1（吸引力动态）：框架沦陷 → 吸引力下降 → 对方不再尊重你的规则
- M3 ↔ M4（投资循环）：框架位置直接决定谁在单向投资
- M3 → M8（关系衰减）：框架的渐进侵蚀是长期关系衰减的核心路径

## M4：投资循环模型

**核心因果链：**

```
健康循环：
  吸引建立（M1）→ 对方开始投入（时间/情绪/注意力）
    → [投资合理化机制] 对方为自己的投入寻找理由 → "我投入了，说明他有价值"
    → 吸引力↑ → 对方更多投入（正反馈）
    → 你的投资适度 → 双向投资 → 关系推进

病态循环：
  你单向投入↑ → 投资差距扩大 →
    → [稀缺性反转] 对方感知"他已经完全被我得到" → 对方不再投入
    → 你的投资 ↑↑（因为焦虑，渴望回收投入）→ 差距继续扩大
    → 框架沦陷（M3）→ 吸引力下降（M1）
```

**变量关系：**

- **正反馈（健康）：** 引导对方投资↑ → 对方对你的重视↑ → 你不需要过度投入 → 投资差距保持平衡
- **负反馈（病态）：** 你投资↑ → 对方投资↓ → 你为了回收投资而更投入 → 差距↑↑
- **临界点：** 对方感知"他已经完全围着我在转了"——这是不可逆的标志

**中间机制：**

投资创造吸引的心理机制是**投资合理化**——人倾向于为自己的行为找理由。当对方在你身上投入了时间、情绪、注意力后，她的潜意识会合理化："我花了这么多心思在他身上，他一定值得。"反之，你单向投入时，对方不需要合理化任何事——她没有投入，所以可以毫无心理负担地放弃你（P06, E0029）。"全部围着女性转会立即导致吸引力下降"（P06）。

**Evidence 支撑：**

P06（投资差距创造吸引）、E0029, E0036, E0045, E0356, E0393, E0433, E0608

**适用边界：**

- **成立条件：** 对方至少对你有基础好感/不排斥——如果完全排斥，引导投资是无效且骚扰性的
- **失效条件：** 如果吸引力从未建立（M1 为负），投资循环不会启动——对方不会投资
- **注意：** "投资"不限于金钱——时间投资、情绪投资（想念、好奇、期待）、注意力投资同等重要
- **操纵风险：** 故意制造投资差距作为一种"操纵手段"——违背 P09（零压力状态最佳）的精神，且容易被对方感知

**与其他 Model 的关系：**

- M4 依赖 M1（吸引力动态）——吸引是投资的前提
- M4 ↔ M2（需求感传导）——需求感暴露 = 单向投资加剧
- M4 ↔ M3（框架动态）——投资差距方向和框架位置方向一致
- M4 → M8（关系衰减）——投资差距持续扩大是长期关系衰减的驱动因

## M5：窗口动态模型

**核心因果链：**

```
吸引建立（M1）→ 对方给出 IOI（主动/投入/接受试探）
  → [信号可读性] 窗口存在但许多人捕捉不到（E0517, E0661）
  → 窗口期有限——不去试探就不会有窗口（E0662）
  → 试探升级（M7）→ 成功 → 关系推进
  → 试探升级 → 失败 → 退回原点重新判断（DM03）
  → 窗口内不行动 → [时间敏感性] 窗口逐渐关闭
    → 对方解读为"他不敢"或"他不感兴趣" → 吸引力下降
```

**变量关系：**

- **窗口的不可逆性：** 窗口打开是可逆的（可以重新打开），但在**这个时间节点**上的窗口错过了就是错过了
- **行动 vs 等待：** 等待对方给出更明确的许可 → 永远不会升级（E0662）
- **临界点：** 对方给出明确 IOI 后如果你不试探 → 窗口可能永久关闭

**中间机制：**

窗口的本质是**升级时机的存在性**（DM01）。它不是"对方已经说 yes"——如果是那样就不需要判断窗口了。窗口是"对方给出的行为线索表明，如果你现在推进，她大概率会接受"。"不去试探就不会有窗口"（E0662）——窗口不是等待出来的，是试探出来的。女性事后往往说"不知道为什么会发生关系"，但在过程中确实有感觉（E0499）——这说明窗口本身是模糊的，需要通过试探来确认。你不试探，永远不会知道。

**Evidence 支撑：**

DM01（窗口判断模型）、DM06（转场/邀约时机判断）  
E0028, E0378, E0476, E0499, E0517, E0661, E0662, E0503

**适用边界：**

- **成立条件：** 前提是吸引已建立（M1）。没有吸引时，"窗口"不存在——那不是窗口，是错觉
- **失效条件：** 如果对方从未给出任何 IOI，则无窗口（如 E0378：态度好但从不主动 = 没窗口，是在吊你）
- **时间敏感性：** 窗口有时间维度——最佳窗口通常较短（几分钟到几天），过了最佳窗口并不等于永远关闭，但重开成本更高
- **错误窗口：** 把礼貌回应误读为窗口是最常见的判断错误

**与其他 Model 的关系：**

- M5 依赖 M1（吸引力动态）——没有吸引就没有窗口
- M5 → M7（升级推进）——窗口判断是升级行动的前提
- M5 受 M2（需求感传导）影响——需求感暴露会加速窗口关闭
- M5 受 M3（框架动态）影响——框架弱者倾向于误读窗口（把礼貌当兴趣）

## M6：一致性维持模型

**核心因果链：**

```
行为一致性（线上/线下一致 + 前后一致）
  → [信任维持机制] 对方对你有稳定的预期 → 预期被持续满足 → 安全感 + 吸引力稳定
  ↓
一致性断裂（确定关系后行为变化 / 线上强线下弱 / 约会前后人设不一）
  → [预期违背机制] 对方发现"你不是我以为的那个人"
  → 信任崩塌 → 吸引力开始流失
  → 对方开始"测试"（试探你还会不会变更多）
  → 用户如果迎合测试 → 框架沦陷（M3）→ 吸引力加速流失
  → 用户如果维持一致性 → 测试逐渐停止 → 关系进入新的平衡
```

**变量关系：**

- **正反馈（强化）：** 一致性↑ → 信任↑ → 你不需要"表演"→ 行为自然→ 一致性更易维持↑
- **负反馈（崩塌）：** 断裂→ 信任↓ → 你焦虑→ 更多不一致→ 信任崩塌加剧↓↓
- **临界点：** 对方从"他变了"变成"他就是这样的人"——判断固化后，修复成本极高

**中间机制：**

一致性的核心不是"不要说谎"，而是**行为线索的稳定性**。女性通过行为线索判断男性（P02），当线索不稳定时（约会时自信、确定关系后变舔狗；线上风趣、线下紧张），对方会感知到"这个人是装的"——这不是信任问题，这是吸引力问题。因为强行为线索的核心是"这个人不需要装"——装了就是弱（P04, E0087）。"确定关系后吸引力下降的根本原因是失去了保持一致性"（DM08）。

**Evidence 支撑：**

P04（一致性是长期基础）、DM08（长期关系健康度判断）  
E0027, E0087, E0175, E0273, E0311, E0569, E0727, E0084

**适用边界：**

- **成立条件：** 一致性在长期关系中的重要性远高于短期互动；短期互动中一致性断裂的影响更小（对方还未形成稳定预期）
- **失效条件：** 如果从一开始就没有吸引力（M1），一致性维持不会创造吸引——它只能维持已有的，不能创造没有的
- **低开高走 vs 高开低走：** Mikey 体系明确主张宁可低开高走不要高开低走——前者是"一致性在变好"，后者是"一致性在断裂"
- **表演型一致：** "刻意保持一致"本身也是一种表演——真正的"一致性"是做自己（P09）

**与其他 Model 的关系：**

- M6 → M1（吸引力动态）：一致性断裂是吸引力流失的核心驱动因
- M6 → M3（框架动态）：一致性断裂 → 对方测试 → 迎合 → 框架沦陷
- M6 → M8（关系衰减）：一致性断裂是长期关系衰减的最常见入口
- M6 被 M2（需求感传导）触发：需求感暴露常导致一致性断裂（从"从容"变成"追逐"）

## M7：升级推进模型

**核心因果链：**

```
标准路径：
  吸引建立（M1）→ 情感共振（聊天深度/情绪共鸣）
  → 窗口出现（M5：对方给出 IOI）
  → [试探-反馈机制] 小剂量施压（P05：肢体/言语试探）
     → 对方接受 → 更大剂量施压 → 升级成功
     → 对方反感 → 坐回原点重新判断（DM03）→ 不继续升级
         
失败路径（常见）：
  - 没有吸引直接升级 → 感知为猥琐（DM03, E0004）
  - 没有共振直接升级 → 感知为冒犯（DM03）
  - 紧张/焦虑地升级 → 触发对方警觉（E0678）
  - 被拒后继续升级 → 失去下一次机会（P05）
  - 越级操作 → 被感知为不懂规则（E0093）
```

**变量关系：**

- **施压-减压节律：** 施压↑ → 对方不适↑ → 减压↓ → 对方放松↓ → 舒适区扩大 → 可再次施压
- **临界事件：** 升级被拒 → 继续升级 = 永久失去；停止升级 = 还有下一次
- **不可逆性：** 被拒后继续施压是不可逆的——"施压过度会直接失去下一次机会"（P05）

**中间机制：**

升级的本质是**逐步扩大对方的舒适区**（P05）。不是一次猛攻，是施压-减压的交替节奏。每一次减压，对方在上一轮施压中形成的不适会转化为新的舒适基线，舒适区因此扩大。另一条核心机制是**信号一致性**：升级时大方从容不会触发警觉，紧张焦虑会（E0678）——因为紧张传递的信号是"我自己都不确定我该不该这样做"。

**Evidence 支撑：**

P05（施压与减压交替）、DM03（升级时机判断）、E0093（不能越级操作）  
E0001-E0005, E0678, E0651, E0712

**适用边界：**

- **成立条件：** 前提是吸引已建立（M1）+ 窗口已出现（M5）。试图在两者缺位时升级 → 必定失败
- **失效条件：** 如果对方性格极度保守，标准升级路径需要大幅减速（E0651）；如果对方已有伴侣，升级的伦理和法律边界完全不同
- **退回机制：** 升级被拒≠关系结束——"反感时坐回原点重新判断"（DM03）是 Mikey 体系的核心止损机制
- **越级操作：** 不同关系阶段可用的升级方式不同——E0093（不能越级操作）

**与其他 Model 的关系：**

- M7 依赖 M1（吸引力动态）+ M5（窗口动态）作为前提
- M7 受 M2（需求感传导）影响——升级时暴露需求感=紧张升级→触发警觉
- M7 受 M3（框架动态）影响——框架强者升级从容；框架弱者升级紧张
- M7 的结果影响 M1（吸引力状态）——升级成功→吸引力↑；升级失败→吸引力可能↓

## M8：关系衰减模型

**核心因果链：**

```
健康维持路径：
  长期保持一致性（M6）+ 控制可得性（不让对方觉得完全得到你）
  + 框架不沦陷（M3）+ 双向投资（M4）
  → 吸引力平稳 → 关系健康

衰减路径（最常见的连锁衰减）：
  入口 1: 一致性断裂（M6）→ "确定关系后行为变了"
  入口 2: 框架侵蚀（M3）→ "被要求改变就改变"（E0084）
  入口 3: 需求感暴露（M2）→ "发生关系后暴露需求感"（DM04）
      ↓
  三种入口汇合 → 对方感知"已经被我完全拿捏" + "他可以被我改变"
      ↓
  → 对方停止投入（M4 反向）
  → 对方开始测试边界（M3 框架测试加剧）
  → 你进一步迎合（M3 沦陷 + M2 需求感暴露）
  → 对方敬畏感消失 → [关键阈值] "过犹不及"（DM08）
  → 吸引力持续流失 → 关系进入不可逆衰退
```

**变量关系：**

- **慢性衰减：** 每次迎合→尊重度下降一点→每次改变→吸引力下降一点（E0084, E0719）——不是单次暴跌，是渐进侵蚀
- **临界点 1：** 对方敬畏感消失（DM08）——"过犹不及"，甜蜜但没有敬畏 = 关系即将失衡
- **临界点 2：** 被驯化完成（E0084）——"你已经被她驯化了，只是你不知道"
- **临界点 3：** 对方开始把注意力转向第三方——这是不可逆的信号

**中间机制：**

长期关系衰减的核心机制是**可得性过度**——"永远不能让女性觉得完全得到了你"（E0739）。不是说要故意若即若离，而是说：当你变成一个完全可预测、完全可控制、完全围绕对方运转的人时，吸引力就消失了。女性真正喜欢的是"她感觉能改变但永远改变不了的男人"（E0719）——这意味着你必须有不可被磨灭的自我核心。一旦你为了维持关系而放弃这个核心（"被驯化"），衰减就开始了。

**Evidence 支撑：**

DM08（长期关系健康度判断）、P04（一致性是长期基础）、P06（投资差距创造吸引）  
E0084, E0318, E0528, E0719, E0727, E0739

**适用边界：**

- **成立条件：** 适用于已确定的长期关系（确定关系后数月至数年）；不适用于初期约会/暧昧阶段——那些阶段的衰减属于 M1/M2 的范畴
- **失效条件：** Mikey 体系的长期关系模型假设的是"正常关系的自然衰减"——不适用于：一方出轨后的关系修复、严重价值观冲突、外部强制因素（家庭压力/异地等）
- **不对称性：** Mikey 体系主要从男性视角出发——女性视角下"吸引力衰减"的机制不同（更偏向情感连接断裂）
- **"不安全感"悖论：** "女人就喜欢让她没有安全感的男人"（E0528）和"邀约的前提是安全感"（E0502）看似矛盾但适用于不同维度——前者指关系动态层面的"抓不住"，后者指基本信任层面的安全感。衰减模型中"可得性控制"指前者，不是在说"让对方担心你会出轨"

**与其他 Model 的关系：**

- M8 是所有模型在长期时间轴上的终点——M1-M7 在长期关系中的持续/断裂/衰减的终局
- M6（一致性）→ M8 最常见入口
- M3（框架）→ M8 渐进侵蚀的核心路径
- M2（需求感）→ M8 在"发生关系后"成为加速器
- M4（投资）→ M8 衰减的下游结果
- M1（吸引力）← M8 衰减的最终受害者

## 总结

### 一句话

**Mikey 的世界模型是：吸引力通过行为线索传递的社会地位信号建立；需求感是那个能同时破坏所有正反馈循环的"杀手变量"；框架、一致性、投资差距是吸引力在时间轴上维持或流失的三条基本通路。**

### 与 Phase 0-2 的关系

| Phase | 产出 | Mental Model 如何使用 |
|-------|------|---------------------|
| Phase 0 | 审计报告 | 确认方向：Mental Model 而非 Rule System |
| Phase 1 | Expertise Model | 感知→诊断→预测→干预的能力树，Mental Model 为诊断提供因果基础 |
| Phase 2 | Decision Flow | Gate 2（根因定位）直接使用 Mental Model 的因果链；Gate 3（理论覆盖）使用 6 个核心变量 |
| **Phase 3** | **Mental Model** | **8 条因果链 + 中间机制 + 边界条件** |

### 下游影响

- **Phase 4（Pattern Library）：** 15 个 Pattern 应按 Mental Model 重新归类——每个 Pattern 是某条因果链在一个具体场景的实例化
- **Phase 5（Knowledge Graph）：** 6 个核心变量 + 8 条因果链 = 知识图谱的核心结构和边
- **Phase 6（Reasoning Engine）：** 推理引擎的核心逻辑：识别变量状态 → 追溯因果链 → 定位根因 → 设计干预
