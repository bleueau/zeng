## 1. 设计理念

### 1.1 为什么需要 Pattern Library

Phase 2 Decision Flow 中，Gate 1（一眼判断）需要将用户案例与已知模式做匹配。没有 Pattern Library，Gate 1 只能靠 LLM 零-shot 判断——这在专业诊断场景下不可靠。

Phase 3 的 8 个 Mental Model 描述了关系世界的因果链。但 Mental Model 太抽象——"需求感传导模型"不能直接告诉 Gate 1 "这个案例匹配什么"。

Pattern 是 Mental Model 在具体场景中的**实例化**：
- Mental Model: 需求感暴露 → 对方感知已拿捏 → 停止投入 → 吸引力下降
- Pattern: 用户约会后高频发消息 → 对方回复从每天变成每三天 → 用户更焦虑→发更多 → 对方彻底不回

### 1.2 Pattern 设计的五大原则

1. **来自 Evidence，不是 AI 发明**——每个 Pattern 的触发条件和常见表现必须有 Evidence 或 Case 中的原型
2. **支持模糊匹配，不是精确匹配**——Pattern 是"原型"（prototype），不是"规则"（rule）。用户案例不需要 100% 匹配才识别
3. **可区分性**——每个 Pattern 标注易混淆模式，防止 Gate 1 误匹配
4. **信号权重分级**——强信号（出现即高匹配）vs 弱信号（辅助确认），帮助 Gate 1 计算匹配度
5. **可操作**——识别 Pattern 后直接指向可能的行动方向（Gate 5）

### 1.3 与 Phase 3 Mental Model 的映射

每个 Pattern 引用至少一个 Mental Model（M1-M8）。Mental Model 解释"为什么"，Pattern 解释"这看起来像什么"。

## 2. Pattern 分类体系

```
                       关系阶段时间线
 陌生 ──────→ 熟悉 ──────→ 暧昧 ──────→ 亲密 ──────→ 长期
  │             │             │             │             │
  └─ 早期(E) ───┘             │             │             │
                  └───── 中期(M) ───────────┘             │
                                       └───── 长期(L) ────┘
                  └─────────── 跨阶段(X): 任何阶段 ────────┘
```

| 分类 | 代码 | 关系阶段 | 数量 | 核心问题 |
|------|------|---------|------|---------|
| **早期** | E01-E11 | 陌生→熟悉→暧昧初期 | 11 | 吸引是否建立？是否应该继续？ |
| **中期** | M01-M12 | 暧昧→亲密 | 12 | 如何推进？窗口在哪？ |
| **长期** | L01-L10 | 亲密→长期关系 | 10 | 吸引力在流失吗？框架还在吗？ |
| **跨阶段** | X01-X07 | 任何阶段 | 7 | 用户的认知和状态问题 |

**总计：40 个 Pattern**

## 3. 早期阶段 Pattern

### E01: 搭讪后失联模式

**一句话定义：** 搭讪现场互动尚可，加微信后对方不回复或敷衍式回复，最终完全失联。

**触发条件：**
- 搭讪后加了微信
- 第一条消息后对方不回复，或回复一次后不再回复
- 对方回复态度敷衍（"嗯""好的"等无延展回复）

**常见表现：**
- 用户说"当场聊得挺好的，回去就再也没理我"
- 用户发第一条消息对方回了，第二条石沉大海
- 用户反复纠结"是不是我发的这条有问题"
- 对方朋友圈没有屏蔽但从不回复

**背后原因：**
- 根因不在"微信消息怎么发"，而在搭讪现场没有建立吸引
- 对方加微信是出于礼貌/不拒绝，不是出于兴趣
- 现场互动中缺乏强行为线索传递（紧张/讨好/不自然）

**相关 Mental Model：** M1（吸引力动态）、M7（升级推进——搭讪是一次微型升级）
**相关 Principle：** P02（潜沟通）、P10（吸引先于技术）、P07（自我价值感）
**相关 Evidence：** DM07, E0320, E0391, E0563, E0589

**可能动作：**
- 检查搭讪现场表现和朋友圈展示面（DM07）
- 如果是现场问题→提升行为线索质量
- 如果是展示面问题→优化朋友圈
- 不继续发消息追问——已失联的情况下越追越差

**易混淆模式：**
- vs E03（邀约推脱）: 搭讪后失联是微信层面就断了；邀约推脱是微信上聊着但约不出来
- vs M03（窗口下降）: 窗口下降的前提是曾经有窗口；搭讪后失联是窗口从未打开

**匹配信号权重：**
- 🔴 强信号：加微信后第一条消息就不回复
- 🔴 强信号：对方回复一次后不再回复，且用户又发了多条
- 🟡 弱信号：回复速度慢但内容不敷衍（可能是真忙）
- 🟡 弱信号：对方没有删好友（不等于有兴趣）

### E02: 聊天降温模式

**一句话定义：** 线上聊天从高频高热变为低频低热，对方投入度持续下降，但你仍在主动维持。

**触发条件：**
- 曾经聊天热度不错（对方也主动）
- 现在热度明显下降（回复间隔变长、内容变短、"嗯嗯"式回复增多）
- 用户仍在试图维持原来热度
- 降温是趋势性的（不是偶尔一次）

**常见表现：**
- "以前她会主动找我聊，现在我不找她她就不找我"
- "以前秒回，现在隔好几个小时才回"
- "回复的内容越来越敷衍，以前会展开聊，现在就是嗯嗯好的"
- 用户开始焦虑，每次打开微信都期待她的消息

**背后原因：**
- 最常见：用户在聊天中暴露了需求感（热度远高于对方）
- 次常见：对方遇到了更有吸引力的人（第三方出现）
- 也可能是：聊天内容无聊/重复，对方失去兴趣
- 因果链（M2）：你高热度→对方感知已拿捏→对方不投入

**相关 Mental Model：** M2（需求感传导）、M4（投资循环）、M1（吸引力动态）
**相关 Principle：** P03（需求感是吸引力杀手）、P06（投资差距）
**相关 Evidence：** E0520, E0509, E0378, DM04

**可能动作：**
- 立即降低消息频率和热度，与对方保持一致
- 停止在没有回应时继续发消息
- 等对方主动联系——如果 5-7 天不联系，说明吸引已流失
- 不要问"你怎么了"或"是不是我做错了什么"

**易混淆模式：**
- vs E03（邀约推脱）: 聊天降温是聊天热度下降；邀约推脱是聊得还行但约不出来
- vs M03（窗口下降）: 窗口下降侧重于"升级机会在消失"；聊天降温侧重于"日常互动变冷"
- vs L01（关系降温）: L01 在长期关系中发生；E02 在早期阶段发生

**匹配信号权重：**
- 🔴 强信号：趋势性降温（不是一次两次）+ 你仍在高频主动
- 🔴 强信号：你不找她她就完全不找你
- 🟡 弱信号：偶尔回复慢（可能真忙）
- 🟡 弱信号：回复短但态度友好（可能只是聊天话题耗尽）

### E03: 邀约推脱模式

**一句话定义：** 每当提出邀约，对方以忙/不方便/不确定等理由推脱，但聊天层面态度尚可。

**触发条件：**
- 用户提出邀约（见面/约会）
- 对方以各种理由拒绝或推脱
- 聊天层面对方回复态度尚可（如果聊天也冷→先看 E02）
- 至少 2 次邀约被推脱（一次可能是真有事）

**常见表现：**
- "她说最近很忙，等忙完再说"
- "她说周末不一定有空，到时候再看"
- "她说平时要上班周末要陪家人"
- 每次邀约都有不同的理由
- 但微信上问她"在干嘛"之类的，她会回

**背后原因：**
- 核心判断：对方不想见你，但不想直接拒绝（留一条备胎）
- 底层机制（M5）：窗口不存在。吸引不足或根本没有。她把线上聊天当作消遣，但不愿投入"见面"这个更高级别的投资
- DM06 的判断逻辑：平日忙+假日也忙=不想见你

**相关 Mental Model：** M5（窗口动态）、M1（吸引力动态——吸引不足）
**相关 Principle：** P10（吸引先于一切技术）
**相关 Evidence：** DM06, E0545, E0547, E0573

**可能动作：**
- 判断是真忙还是借口：真忙=她会主动约替代时间；借口=永远"到时候再说"
- 如果是借口→停止邀约，回到建立吸引（M1）
- 如果还在微信上聊→可以保持但降低投入，不以见面为目的
- 关键信号：她说"周末再看"但周末从不主动说有空→不想见你

**易混淆模式：**
- vs E02（聊天降温）: 聊天降温是聊天层面就冷了；邀约推脱是聊天还行但约不出来
- vs M05（升级被拒）: 升级被拒是约会中的肢体/暧昧推进被拒；邀约推脱是约会本身约不出来
- vs E01（搭讪后失联）: 搭讪后失联是微信第一步就断了；邀约推脱是微信上聊着但进入不了线下

**匹配信号权重：**
- 🔴 强信号：2+ 次邀约推脱+从不主动约替代时间
- 🔴 强信号：平日说忙、假日也说忙
- 🟡 弱信号：第一次被拒（可能是真忙，再约一次）
- 🟡 弱信号：对方说"等忙完"但她确实处于忙期（需时间验证）

### E04: 搭讪焦虑模式

**一句话定义：** 用户有搭讪意愿但在行动时被焦虑/恐惧阻止，或严重紧张导致表现变形。

**触发条件：**
- 用户表达了搭讪意愿但迟迟不行动
- 搭讪时严重紧张：声音颤抖、眼神逃避、大脑空白
- 搭讪失败后产生心理创伤，不敢再去那个地方
- 新手（缺乏搭讪经验）

**常见表现：**
- "我看到她很想上去说话，但腿就是迈不出去"
- "想了一百种开场白，走到她面前全忘了"
- "上次被拒了，我再也不敢去那个地方了"
- "我总觉得旁边有人在看我"

**背后原因：**
- 把搭讪赋予了太多意义——"这次搭讪成功/失败=我这个人行/不行"（P07 反面）
- 缺乏经验导致的自然焦虑——不是心理问题，是经验问题
- 认知扭曲：把"被拒绝"和"我不配"画等号

**相关 Mental Model：** M1（吸引力动态——紧张传递弱行为线索，降低吸引）
**相关 Principle：** P07（自我价值感）、P09（零压力状态最佳）
**相关 Evidence：** E0101, E0361, E0418, E0205

**可能动作：**
- 降低搭讪的心理权重——"只是上去说句话，不是去决定终身大事"
- 从小目标开始：不是"要拿到微信"，而是"今天要跟 3 个陌生人说话"
- 脱敏训练：多做→焦虑自然降低
- 不是"先消除焦虑再搭讪"→是"先搭讪，搭多了焦虑自然降"

**易混淆模式：**
- vs X03（不配得感）: 搭讪焦虑是情境性的（只在搭讪时焦虑）；不配得感是持续性的（关系中一直觉得配不上）

**匹配信号权重：**
- 🔴 强信号：描述中有大量"怕""不敢""紧张"等情绪词
- 🔴 强信号：搭讪被拒后出现"再也不敢去那个地方"的回避行为
- 🟡 弱信号：只是第一次搭讪的正常紧张

### E05: 展示面坍塌模式

**一句话定义：** 搭讪现场表现不错，但朋友圈/线上展示面与现场人设严重不符，导致对方失去兴趣。

**触发条件：**
- 搭讪现场对方兴趣尚可
- 加了微信后对方翻看朋友圈
- 朋友圈内容与现场表现差距大（现场自信/朋友圈空洞或自贬）
- 线下有趣 vs 线上无聊——"这个人好像没什么生活"

**常见表现：**
- "当场聊得挺好，回去就不理我了"
- 朋友圈没有内容，或内容很负面
- 朋友圈与个人真实价值不匹配（有价值但不会展示）
- 对方看了朋友圈后态度变化明显

**背后原因：**
- 现代社会，女性在决定是否投入前会查看线上展示面
- 朋友圈是"你是谁"的延伸证据——现场表现好但朋友圈空洞=信号不一致（M6 萌芽）
- 缺乏展示面=缺乏社会证明→对方不确定你是否"正常"

**相关 Mental Model：** M1（吸引力动态——展示面是吸引的线上延伸）、M6（一致性——线上线下不一致）
**相关 Principle：** P02（潜沟通——朋友圈是静态的行为线索）、DM07
**相关 Evidence：** DM07, E0420

**可能动作：**
- 检查朋友圈：是否有生活内容？是否有社会证明？是否与现场人设一致？
- 如果没有朋友圈→先搭讪积累经验，同步建设朋友圈
- 不必过度包装——真实展示生活即可，"正常人的生活"就够了

**易混淆模式：**
- vs E01（搭讪后失联）: 展示面坍塌是现场表现好但朋友圈拖后腿；搭讪后失联是现场就没建立吸引
- vs M06（线上线下不一致）: 展示面坍塌侧重"静态资料"；线上线下不一致侧重"行为模式"

**匹配信号权重：**
- 🔴 强信号：现场对方给出 IOI，加了微信浏览朋友圈后态度急转
- 🔴 强信号：朋友圈长期无内容或内容与一个有趣的人不匹配
- 🟡 弱信号：朋友圈没问题但对方仍不回复（根因可能是其他因素）

### E06: 阶段越级模式

**一句话定义：** 在关系阶段不匹配的情况下，使用更高阶段的策略或行为，导致对方反感。

**触发条件：**
- 用户在不熟悉阶段表白、追问关系、要求确认
- 约会初期使用长期关系的逻辑（"你要对我负责"）
- 在没有吸引时讨论性话题
- 在对方还未建立安全感的阶段要求单独见面

**常见表现：**
- "我跟她说我喜欢她，她就不理我了"
- "我只是表达了我的真心，为什么她反而躲我"
- "我们聊了两天我觉得可以约她出来，她拒绝了"
- "我问他我们是什么关系，他说'普通朋友'"

**背后原因：**
- 核心原则：不同阶段有不同的规则和操作空间（E0093）
- 底层机制（M7）：没有共振直接升级=让对方不舒服
- 表白=要求对方做决定——在对方还未投入时要求做决定，答案永远是 no
- 越级操作传递给对方的信息："这个人不懂社交规则"

**相关 Mental Model：** M7（升级推进——阶段不匹配时升级必然失败）、M5（窗口动态——窗口只在特定阶段打开）
**相关 Principle：** P10（吸引先于技术）、P05（施压减压交替）
**相关 Evidence：** E0093, DM03, DM06

**可能动作：**
- 退回当前阶段的正确操作——如果还在陌生阶段，先建立舒适感
- 口诀：吸引→舒适→暧昧→确认关系（不能跳步）
- 如果在错误阶段做了越级操作→停止越级行为，退回，不解释

**易混淆模式：**
- vs E03（邀约推脱）: 阶段越级是用户在不合适的时机做了不合适的事；邀约推脱是对方根本没兴趣
- vs M05（升级被拒）: 升级被拒是在正确阶段但施压过度；阶段越级是阶段本身就不对

**匹配信号权重：**
- 🔴 强信号：用户在认识不到一周内表白/追问关系
- 🔴 强信号：用户在没有 IOI 的情况下讨论性话题
- 🟡 弱信号：在聊天中试探性地问了"我们算什么"但对方没有明确拒绝

### E07: 线上热线下冷模式

**一句话定义：** 微信上聊得火热，但见面时对方表现冷淡或反差巨大，无法将线上热度转化为线下吸引。

**触发条件：**
- 线上聊天对方投入、主动、有 IOI
- 约出来见面时对方冷淡/拘谨/不如线上主动
- 线下互动无法重现线上的热度和舒适感
- 见面后线上热度也下降（进入 E02 或 M04）

**常见表现：**
- "微信上她话特别多，见了面基本不说话"
- "网上聊得可好了，一见面就尴尬"
- "见面时不知道说什么，跟网上完全不一样"
- "见完之后她又不怎么回消息了"

**背后原因：**
- 线上交流缺乏潜沟通信息（肢体/眼神/气场）——你可以精心设计文字，但线下你的紧张和不自然无法隐藏
- P02 的推论：线下才是真正的潜沟通战场
- 可能原因 1：用户线下紧张，行为线索弱→线下吸引低于线上预期
- 可能原因 2：对方在线上是"表演型社交"（她不是对你有兴趣，她对所有人都是这样聊天）

**相关 Mental Model：** M1（吸引力动态——线下才是吸引力的主战场）、M6（一致性——线上线下不一致）
**相关 Principle：** P02（潜沟通传递核心信息）、P04（一致性）
**相关 Evidence：** DM06（应该在微信上约出来，不是线上聊到暧昧）, E0503

**可能动作：**
- 核心原则：线上以约定见面为目标，不把线上当主战场（DM06）
- 尽快约出来——线上聊得越久，线下落差可能越大
- 见面后复盘：是自己的线下表现问题还是对方的问题
- 如果是自己紧张→练线下互动；如果是对方线上热线下冷→这不是你一个人能解决的

**易混淆模式：**
- vs E02（聊天降温）: 聊天降温是线上变冷；线上热线下冷是线上仍热但线下不热
- vs M06（线上线下不一致）: M06 侧重于"你自己的"线上线下不一致；E07 侧重于"你和对方之间"的线上线下温差

**匹配信号权重：**
- 🔴 强信号：线上对方主动、投入，线下沉默、冷淡
- 🔴 强信号：见面后对方线上态度也明显下降
- 🟡 弱信号：第一次见面尴尬（可能是双方都紧张）

---

### E08: 礼貌性互动模式

**一句话定义：** 对方回复态度很好、很有礼貌，但从不主动发起互动、从不提供话题、从不推进关系。

**触发条件：**
- 对方每次都会回复（且态度不差）
- 但对方从不主动发消息
- 对方的回复是"回应"而非"延展"——你问什么她答什么
- 你不会觉得被拒绝，但你也感受不到她在投入

**常见表现：**
- "她回复态度挺好的，但我不找她她就不找我"
- "她每次都会回我，但我总觉得哪里不对"
- "聊天内容一直是我在找话题"
- "她说她这个人就是不太主动"

**背后原因：**
- 这是 Mikey 体系中最具辨识度的判断之一：态度好但不主动=没有窗口，是在吊你（E0378）
- 底层机制（M4）：对方没有投资——投资不只是回复消息，是主动提供话题、主动关心、主动找你
- 礼貌回复 ≠ 有兴趣——她只是不想当坏人

**相关 Mental Model：** M4（投资循环——对方零投资）、M5（窗口动态——窗口不存在）
**相关 Principle：** P10（吸引先于一切技术）
**相关 Evidence：** E0378, DM01, E0312

**可能动作：**
- 核心判断：此人没有窗口，不要幻想
- 可以停止主动——如果她不找你，答案已明确
- 不要把礼貌当兴趣——这是最常见的判断错误
- 如果想要确定性：停止主动 1-2 周，看她是否主动联系

**易混淆模式：**
- vs E03（邀约推脱）: 礼貌性互动是对方不拒绝但也不推进；邀约推脱是对方明确拒绝邀约但态度还好
- vs E10（备胎模式）: 高度重叠——礼貌性互动是备胎模式的前提条件

**匹配信号权重：**
- 🔴 强信号：从未主动发起过对话+回复内容不延展话题
- 🔴 强信号：你不找她后她完全不找你
- 🟡 弱信号：偶尔主动但只是有事才联系（不是社交性主动）

---

### E09: 搭讪循环失败模式

**一句话定义：** 用户大量搭讪但从未转化为有效约会，陷入搭讪→加微信→不回复→继续搭讪的无效循环。

**触发条件：**
- 搭讪数量大（几十到几百次）
- 但几乎没有任何后续发展
- 用户专注于搭讪技术（开场白/技巧）但忽略吸引建立
- 搭讪本身变成了目的，忘了目的是约会/关系

**常见表现：**
- "我搭了很多人，但没一个能约出来的"
- "每次搭讪都能加到微信，然后就没有然后了"
- "我学了各种开场白，还是没有用"
- "搭讪成功但没有后续"——其实搭讪并没有成功，只是加了微信

**背后原因：**
- Mikey 见过搭讪上万次却没有结果的人（E0562）——证明搭讪能力≠约会成功
- 底层机制（M1）：搭讪只是"认识"的工具——如果搭讪中没有建立任何吸引，加了微信也不会转化
- 用户把"加到微信"当成了"搭讪成功"——这是一个认知陷阱

**相关 Mental Model：** M1（吸引力动态——搭讪中建立吸引是关键）、M7（升级推进——搭讪是升级的第一步）
**相关 Principle：** P10（吸引先于技术）、P02（潜沟通——搭讪中的行为线索比开场白重要）
**相关 Evidence：** E0562, DM07, E0519, E0320

**可能动作：**
- 停止追求搭讪数量，专注搭讪质量
- 检查：搭讪中对方是否真的给出了 IOI？还是只是礼貌回应？
- 搭讪的目标不是"加到微信"→而是"传递足够的行为线索让对方愿意回复微信"
- 如果搭讪成功率高但微信转化率低→问题在展示面或现场行为线索
- 如果搭讪成功率本身就很低→问题在搭讪方式（紧张/不自然/开场不行）

**易混淆模式：**
- vs E01（搭讪后失联）: E01 是单个案例，E09 是系统性问题（反复出现）
- vs E04（搭讪焦虑）: E09 的用户不一定焦虑——他们可能在搭讪层面做得很顺，只是无法转化

**匹配信号权重：**
- 🔴 强信号：搭讪数量多但约会数量为零
- 🔴 强信号：用户炫耀搭讪数量而非约会结果
- 🔴 强信号：用户着迷于各种搭讪技巧的学习

---

### E10: 备胎/吊着模式

**一句话定义：** 对方保持友好但不承诺的互动，偶尔给出模糊信号让你不舍得放弃，但从未真正投入。

**触发条件：**
- 对方态度友好但不主动（E08 的升级版）
- 对方偶尔给出模糊的"可能有机会"信号
- 你在关系中投入远大于对方
- 关系状态长期没有进展
- 对方可能同时有多个类似关系

**常见表现：**
- "她说她现在不想谈恋爱"
- "她有时候对我特别好，有时候又很冷淡"
- "我们已经这样聊了大半年了"
- "我送她礼物她会收，约她她有时候出来有时候不出来"
- 用户描述中充满"可能""也许""说不定"

**背后原因：**
- 对方把你当备胎——不是她不知道你喜欢她，是她知道但假装不知道
- 底层机制（M4）：她不需要投入，因为你在持续投入。只要你不停止投入，她永远不会"选择"你——因为她不需要选，她已经拥有了
- 偶尔给出的"糖"（热一次）是为了让你不放弃——不是窗口，是维持备胎机制

**相关 Mental Model：** M4（投资循环——单向投资的病态循环）、M2（需求感传导——你在暴露需求感）
**相关 Principle：** P03（需求感）、P06（投资差距）
**相关 Evidence：** E0378, DM01, E0520

**可能动作：**
- 核心策略：打破单向投资循环——停止投入
- 停止主动一段时间→看她是否主动联系→如果不联系→答案明确
- 不要问"我们是什么关系"——你不需要她给你答案，你需要看她的行为
- 如果你觉得"万一她其实喜欢我呢"→看行为，别看你的期待

**易混淆模式：**
- vs E08（礼貌性互动）: 礼貌性互动是稳定地不主动；备胎模式是偶尔给出希望让你不放弃
- vs M03（窗口下降）: 窗口下降是曾经有窗口在关闭；备胎模式是窗口从未真正打开过
- vs M12（热冷交替）: 热冷交替是行为模式；备胎模式是关系结构的判断

**匹配信号权重：**
- 🔴 强信号：已持续 3 个月以上无进展 + 你持续投入
- 🔴 强信号：对方偶尔给出正面信号让你不放弃，但不持续
- 🔴 强信号：对方收礼物/接受好意但从不回馈同等投入
- 🟡 弱信号：关系初期的不确定性（初期正常，超过 1-2 个月不正常）

---

### E11: 小白速成模式

**一句话定义：** 纯小白学员通过正确指导和执行力，在极短时间内从零到成功约会/收尾。（正面模式）

**触发条件：**
- 用户是纯新手（无搭讪/约会经验）
- 用户听话照做（不反复质疑指导）
- 有系统指导
- 用户不纠结"为什么"，专注"做什么"

**常见表现：**
- "我没搭讪过，但我决定今天去试"
- "你让我做什么我就做什么"
- 快速行动→快速调整→快速拿到结果
- 不纠结理论，不追问"这样做的原理是什么"

**背后原因：**
- P09（零压力状态）的反面印证——新手因为"什么都不懂"反而没有心理包袱，不执着于结果
- 行为先于理解——先做了拿到正反馈，信心自然建立
- 内在限制比技术缺乏更大的障碍——听话的新手绕过了自我怀疑的阶段

**相关 Mental Model：** M1（吸引力建立——通过大量实战快速积累行为线索）、M7（升级推进——在指导下正确执行）
**相关 Principle：** P09（零压力状态最佳）、P07（自我价值感不依赖外在）
**相关 Evidence：** E0205, E0066

**可能动作：**
- 这不是一个"问题模式"而是一个"正面模式"——识别到后保持方向
- 重点：维持"听话照做"的节奏，不要让用户开始"自我怀疑"
- 作为教练：给具体行动指令而非理论解释

**易混淆模式：**
- vs X04（零压力成功）: 相关但不同——小白速成是"从零开始"的特例；零压力成功是一个更广泛的正面模式

**匹配信号权重：**
- 🔴 强信号：纯新手 + 高执行力 + 无理论负担
- 🔴 强信号：用户说"我不懂但我去试试"

## 4. 中期阶段 Pattern

### M01: 需求感暴露模式

**一句话定义：** 用户通过行为线索（高频主动、追逐反应、聊天热度不对等）传递了"我比你更需要这段关系"的信号，导致对方停止投入。

**触发条件：**
- 用户消息频率明显高于对方
- 用户在对方不回应时继续发消息
- 用户的聊天热度持续高于对方
- 用户因为对方的反应产生强烈情绪波动
- 用户为了拿到结果放下自己的标准

**常见表现：**
- "我给她发了 5 条她只回了一条"
- "她不回我我就很焦虑，然后又发了几条"
- "我以前不是这样的，现在变得特别在意她"
- "为了约她出来我答应了很多条件"
- 用户开始看各种"怎么回复"的攻略——但真正的问题不是怎么回

**背后原因：**
- 核心因果链（M2）：高频主动→对方解码"你已被我拿捏"→对方停止投入→你更焦虑→更多主动
- 需求感不是通过"说了什么"传递的——是通过行为线索（P02）
- "为了打到那一炮连脸都不要了反而打不到"（DM04）——越急切越得不到
- 恶性循环：需求感暴露→吸引力降→用户更焦虑→需求感更多

**相关 Mental Model：** M2（需求感传导——这是 M2 最直接的实例化）、M4（投资循环——单向投资加剧）
**相关 Principle：** P03（需求感是吸引力杀手）、P02（潜沟通传递核心信息）
**相关 Evidence：** DM04, E0194, E0520, E0534, E0509

**可能动作：**
- 第一步（立即）：停止高频主动——把消息频率降到和对方一样
- 第二步（状态）：分散注意力，不要所有空闲时间都在想她
- 第三步（验证）：等 3-5 天不主动→观察她是否主动联系
- 核心原则：你的焦虑是你的事——不要把它变成她的事

**易混淆模式：**
- vs E02（聊天降温）: M01 是"你做了什么导致降温"（因）；E02 是"对方降温了"（果）
- vs X06（认知障碍/自欺）: M01 是行为层面的需求感暴露；自欺是用户不承认自己在暴露需求感

**匹配信号权重：**
- 🔴 强信号：消息频率明显不对等（你 5 条她 1 条）
- 🔴 强信号：对方不回应时你继续发消息
- 🔴 强信号："我不知道怎么了，变得特别在意她"
- 🟡 弱信号：偶尔多发了一条消息（正常，三次以上是模式）

---

### M02: 投资下降模式

**一句话定义：** 对方对关系的投资（时间/情绪/注意力/主动性）持续下降，趋势指向完全退出。

**触发条件：**
- 对方主动发消息频率下降
- 对方回复间隔变长
- 对方不再主动提供话题
- 对方对你的事情不再关心/好奇
- 趋势是持续下降的
- （注意：M02 侧重于对方的投资在下降；M01 侧重于你暴露需求感导致了这个现象）

**常见表现：**
- "她以前会问我今天过得怎么样，现在完全不问了"
- "她回复从秒回变成几小时回"
- "以前她会跟我分享她的日常，现在只说嗯嗯"
- "我感觉她在慢慢退出"

**背后原因：**
- 根因通常在 M01（需求感暴露）或 M03（窗口下降——对方已经没有兴趣）
- 因果链（M4）：你的投资 ↑↑ + 对方投资 ↓↓ → 投资差距持续扩大 → 对方没有投资所以随时可以离开
- 也可能是 M5（窗口关闭后对方自然退出）

**相关 Mental Model：** M4（投资循环——病态循环）、M2（需求感传导——通常是 M02 的根因）
**相关 Principle：** P06（投资差距创造吸引——反向）、P03（需求感）
**相关 Evidence：** E0520, E0312, DM01

**可能动作：**
- 核心：找出投资下降的根因——是需求感暴露？是第三方出现？是自然冷却？
- 如果是需求感暴露→M01 的行动方案
- 如果是第三方→M08 的行动方案
- 如果是自然冷却（吸引从未建立）→止损，不要幻想
- 不要问对方"你怎么了"——这会加速投资下降

**易混淆模式：**
- vs M03（窗口下降）: 投资下降侧重于"日常互动的投入度下降"；窗口下降侧重于"升级机会在消失"
- vs E02（聊天降温）: E02 是早期阶段的投资下降；M02 是中期（已有一定关系基础后）
- vs L01（关系降温）: L01 是长期关系确定后的衰减；M02 是暧昧/约会阶段

**匹配信号权重：**
- 🔴 强信号：趋势性下降（不是偶尔一次）+ 持续 2 周以上
- 🔴 强信号：对方主动联系频率持续下降
- 🟡 弱信号：短期波动（可能只是忙）

---

### M03: 窗口下降模式

**一句话定义：** 曾经存在的升级窗口正在逐渐关闭，对方对推进关系的接受度持续下降。

**触发条件：**
- 曾有过明确 IOI（主动/投入/接受试探）
- 现在对方不再给出升级信号
- 邀约被推脱或不积极回应
- 对方开始避免独处/亲密接触

**常见表现：**
- "以前约她出来很容易，现在各种理由推脱"
- "以前她会主动碰我，现在保持距离"
- "感觉她想保持距离"
- "我该不该表白？"——通常意味着窗口已经快关了

**背后原因：**
- 因果链（M5）：窗口有时间敏感性——不及时推进，窗口会自然关闭
- 关闭原因 1：你迟迟不升级→她解读为"你不感兴趣"或"你不敢"→她转向别人
- 关闭原因 2：你升级方式不对（施压过度/紧张）→触发警觉→窗口关闭
- 关闭原因 3：第三方出现→她的注意力转移
- E0662：你不去试探就永远不会知道窗口——但窗口不等人

**相关 Mental Model：** M5（窗口动态——核心模型）、M7（升级推进——错过了升级时机）
**相关 Principle：** P05（施压减压交替——升级节奏）
**相关 Evidence：** DM01, E0661, E0662, E0378

**可能动作：**
- 核心：窗口在降但还没完全关闭→还有机会，但必须行动
- 做一次明确的试探（不是表白，是行动）→如果对方积极回应→抓紧推进
- 如果对方回避→窗口大概率已关闭→不要继续升级，退回
- 重要：窗口下降≠永远关闭——但再次打开的可能性取决于关闭原因
- 如果是第三方→窗口可能永久关闭

**易混淆模式：**
- vs M02（投资下降）: 投资下降关注日常互动；窗口下降关注升级机会
- vs E03（邀约推脱）: E03 是窗口从未打开；M03 是窗口曾经开过、现在在关
- vs M05（升级被拒）: 升级被拒是你在试探时被拒绝；窗口下降是对方在试探前就表现出回避信号

**匹配信号权重：**
- 🔴 强信号：曾经接受升级试探，现在回避
- 🔴 强信号：从主动约你变成推脱约你
- 🔴 强信号：身体距离明显增大
- 🟡 弱信号：一次推脱（可能是真忙）

---

### M04: 约会后降温模式

**一句话定义：** 约会时气氛良好/正常，但约会后对方的态度明显转冷。

**触发条件：**
- 最近有一次约会
- 约会后对方回复变慢/变冷淡
- 约会时气氛看起来没问题
- 用户困惑：不知道哪里出问题了

**常见表现：**
- "约会时聊得挺好的，回来就不理我了"
- "见面时她还挺热情的，回去后完全变了"
- "我不知道自己做错了什么"
- 用户试图回忆约会中的每个细节找原因

**背后原因：**
- 原因 1（最常见）：约会中发生了用户没注意到但对方在意的事——可能是某句话、某个行为、某个信号
- 原因 2：施压过度（E0001-E0005）——约会中升级过度，对方当场没表示反感但回去后决定"pass"
- 原因 3：一致性断裂（M6）——约会时表现和约会后表现不一致（约会后变得特别黏）
- 原因 4：对方在约会中确认了"没有吸引"——约会前有模糊期待，见面后确认不感兴趣

**相关 Mental Model：** M6（一致性维持）、M7（升级推进——施压过度的边界）
**相关 Principle：** P05（施压减压）、P04（一致性）
**相关 Evidence：** E0013, DM03, DM08

**可能动作：**
- 不追问、不道歉、不暴露焦虑——这 3 件事会让你从"约会可能有问题"变成"你这个人有问题"
- 等 2-3 天→如果她不主动联系→说明问题严重
- 复盘约会行为：是否施压过度？是否说了不该说的话？是否表现不一致？
- 如果她主动联系了→说明问题不大，可能是她需要时间消化

**易混淆模式：**
- vs M05（升级被拒）: 升级被拒是约会中明确的拒绝事件；约会后降温是没有明确拒绝但态度转冷
- vs E02（聊天降温）: 聊天降温是渐进性的；约会后降温是事件触发性的（约会是一个明确的转折点）

**匹配信号权重：**
- 🔴 强信号：以一次约会为明确分界点前后的态度变化
- 🔴 强信号：约会后 24-48 小时内态度急转
- 🟡 弱信号：约会后回复速度略降但态度未变（可能需要时间消化）

### M05: 升级被拒模式

**一句话定义：** 在约会中尝试肢体/暧昧升级时被对方拒绝、回避或表达反感。

**触发条件：**
- 约会中用户尝试升级（牵手/拥抱/接吻/性暗示等）
- 对方明确拒绝、回避、躲开、或表达不适
- 此后约会氛围变僵

**常见表现：**
- "我试着牵她的手，她缩回去了"
- "我想抱她，她推开了"
- "我说了比较暧昧的话，她脸色变了"
- 升级失败后用户不知道该怎么办——是继续还是退回？

**背后原因：**
- 原因 1：升级时机不对——窗口不存在（M5）或吸引不足（M1）
- 原因 2：升级方式不对——紧张/焦虑/不够大方从容（E0678）
- 原因 3：对方节奏比你慢——你跳级了（E06 越级）
- 不是"升级"这个行为本身有问题——是"怎么升级"和"什么时候升级"有问题

**相关 Mental Model：** M7（升级推进——核心模型）、M5（窗口动态——窗口判断是升级的前提）
**相关 Principle：** P05（施压减压交替）、P10（吸引先于技术）
**相关 Evidence：** DM03, E0001-E0005, E0678, E0651

**可能动作：**
- 核心原则：反感时坐回原点重新判断（DM03）
- 不要继续升级！——继续升级=失去下一次机会
- 退回舒适区→重新建立共振→再判断窗口
- 不要为升级道歉——道歉=你承认自己做错了，反而让对方确认"你确实越界了"
- 如果你从容退回→反而可能让对方觉得"他不是在强求，他只是试了一下"

**易混淆模式：**
- vs M04（约会后降温）: 升级被拒是明确的拒绝事件；约会后降温是没有明确拒绝但态度变冷
- vs M02（投资下降）: 投资下降是趋势性的；升级被拒是事件性的

**匹配信号权重：**
- 🔴 强信号：对方明确躲开/推开/说"不要"
- 🔴 强信号：升级失败后对方态度明显变冷
- 🟡 弱信号：对方没有拒绝但也没有热情回应（可能只是害羞）

### M06: 线上线下不一致模式

**一句话定义：** 用户线上聊天表现优秀（有趣/自信/松弛），但线下见面时表现拘束/紧张/不自然，导致吸引力断崖。

**触发条件：**
- 线上聊天对方投入且有兴趣
- 约出来见面时用户表现与线上反差大
- 见面后对方态度下降

**常见表现：**
- "我线上话特别多，见面就不知道说什么"
- "线上我都能撩她，线下完全不敢"
- "见面就紧张，说话也结巴"
- "见面前我准备了好多话题，结果一个都没用上"

**背后原因：**
- P02 的核心运作：线上缺少潜沟通维度——你可以编辑、思考、控制文字；线下无法隐藏紧张和不自然
- 底层机制（M6）：线上和线下不一致=你在传递两种不同的行为线索→对方感知到不一致→信任和吸引双降
- 用户在线下无法维持线上的人设——这本身就是"装"的一种形式

**相关 Mental Model：** M6（一致性维持——线上线下不一致是最常见的断裂形式）
**相关 Principle：** P02（潜沟通）、P04（一致性）、P09（零压力）
**相关 Evidence：** P04, E0273, E0274, DM08

**可能动作：**
- 根本解决：不是"学线下聊天技巧"，是"让线下表现和线上一样自然"
- 短期：降低线上表现不要太"完美"→让对方对线下的你有合理预期（P04：宁可低开高走）
- 长期：多进行线下互动练习，减少对文字的依赖
- 原则：生活中的你决定约会中的你（E0521）——改善线下社交能力

**易混淆模式：**
- vs E07（线上热线下冷）: E07 侧重于双方热度不一致（对方线上热线下冷）；M06 侧重于你自己的线上和线下不一样
- vs E04（搭讪焦虑）: 搭讪焦虑是搭讪时的焦虑；M06 是有交流基础后见面时的紧张

**匹配信号权重：**
- 🔴 强信号：用户自述"我线上会聊线下不会聊"
- 🔴 强信号：见面后对方态度下降 + 用户承认线下紧张
- 🟡 弱信号：第一次见面小紧张且对方没太在意

### M07: 技术依赖陷阱

**一句话定义：** 用户执着于学习各种话术/技巧/套路，但忽略了根本问题——没有吸引，或自身状态有问题。

**触发条件：**
- 用户反复询问"她这句话我该怎么回"
- 用户大量搜索/学习各种技巧
- 用户相信"只要用对方法她就会喜欢我"
- 但结果始终不理想——换一个技巧还是一样

**常见表现：**
- "你教我一个话术，我下次试试"
- "我看别人这样做就成功了，为什么我不行？"
- "我学了推拉/框架/废测回应，但还是没进展"
- 用户把每次失败归因于"方法不对"——继续找新方法

**背后原因：**
- P10 的核心：技术只能强化吸引，不能创造吸引。没有吸引导弹也无法命中目标
- P02 的核心：话术是表沟通——真正的信号由潜沟通传递。你背了正确的话术但紧张地念出来=没用
- 底层机制（M1）：用户相信"方法→结果"的线性逻辑，但吸引是"你是个什么样的人→对方感觉到什么"的非线性过程

**相关 Mental Model：** M1（吸引力动态——技术不能创造吸引）、M2（需求感——学技巧本身就是需求感高的表现）
**相关 Principle：** P10（吸引先于一切技术）、P02（潜沟通传递核心信息）
**相关 Evidence：** E0316, E0521, E0383, DM02

**可能动作：**
- 停止学习新技巧——你不需要更多技巧，你需要更多吸引
- 回到基础：你的行为线索在传递什么？你是放松还是紧张？你是在聊天还是在"执行战术"？
- 核心转变：从"我该说什么"变成"我现在是什么状态"

**易混淆模式：**
- vs E09（搭讪循环失败）: 技术依赖不限于搭讪——也适用于聊天/约会/长期关系中的所有技术依赖

**匹配信号权重：**
- 🔴 强信号：用户反复追问"她 X 我该说什么"
- 🔴 强信号：用户提到"学了很多技巧但还是不行"
- 🟡 弱信号：问一两次具体回复建议（正常求助，不是模式）

### M08: 第三方介入模式

**一句话定义：** 关系降温或对方态度变化的根因是出现了另一个有吸引力的对象。

**触发条件：**
- 关系之前进展正常
- 突然降温且没有明确原因（不是你的行为变化）
- 对方变得神秘/不再分享行踪
- 对方在某些时间段完全消失

**常见表现：**
- "以前天天聊，现在突然不见了"
- "她好像在跟别人聊天"
- "她开始回避跟我见面"
- 用户从"感觉大事不妙"到通过各种方式确认第三方

**背后原因：**
- M1+M5 的交叉：出现了另一个传递更强行为线索的对象→对方的注意力和窗口转向了第三方
- 不一定是你做错了什么——但一定是你没有足够强到独占她的注意力
- 窗口关闭（M5）+ 投资转移（M4）= 你在她心中的位置被替代

**相关 Mental Model：** M1（吸引力动态——被更强的信号取代）、M4（投资循环——对方的投资转向第三方）、M5（窗口动态——窗口因为第三方而关闭）
**相关 Principle：** P01（关系动态决定吸引力）
**相关 Evidence：** E0233, E0237, P01

**可能动作：**
- 不要追问第三方——你的不安全感会进一步杀吸引
- 不要试图"竞争"——你没法和一个看不见的对手竞争
- 策略：保持你的框架→如果她的窗口真的转向了第三方，你的追逐只会让她更快决定
- 如果关系还早→止损：她不选择你本身就是答案
- 如果关系已深→等第三方自然消退（如果消退的话）

**易混淆模式：**
- vs M02（投资下降）: 投资下降原因是内部（你/她）；第三方介入是外部因素
- vs M03（窗口下降）: 窗口下降可以是自然过程；第三方介入是外部加速器

**匹配信号权重：**
- 🔴 强信号：没有明显原因的关系突然降温
- 🔴 强信号：对方在某些时间段规律性地消失
- 🟡 弱信号：对方社交媒体上出现新互动（不能被确认）

### M09: 多线操作失衡模式

**一句话定义：** 用户同时与多个对象互动，因精力分散导致所有线都下滑，或对某一方过度投入打破了多线平衡。

**触发条件：**
- 用户同时在发展多条关系线
- 某一阶段后所有线都出现了问题
- 用户无法判断应该主攻谁
- 用户在其中一条线上投入了大量精力

**常见表现：**
- "我同时在聊三个，但现在都不理我了"
- "有一个我特别喜欢，另外几个就懒得回了"
- "不知道选哪个，结果哪个都没抓住"
- "其中一个对我特别好，我不知道该怎么办"

**背后原因：**
- M4 的运作：多线操作的本质是分散投资——这让你在各条线上都能保持低需求感
- 但如果开始对某条线过度投入（M2）→其他线自动感知你"人在心不在"→其他线失联
- 如果所有线都出问题→不是多线操作的问题，是你在所有线上都没有建立吸引（M1）

**相关 Mental Model：** M2（需求感传导——在某条线上暴露需求感会破坏多线平衡）、M4（投资循环——多线是分散投资的策略）
**相关 Principle：** P03（需求感）、P06（投资差距）
**相关 Evidence：** E0066（成都程序员多线操作成功案例）

**可能动作：**
- 如果某条线掉了→不要追，保持其他线的投入
- 如果所有线都掉了→检查自己的行为线索是否在每条线上都出了问题
- 不要因为"失去了一条线"而恐慌性地追其他线

**易混淆模式：**
- vs M02（投资下降）: M02 是单条线的投资下降；M09 是多条线同时出问题
- vs E02（聊天降温）: E02 是早期单线降温

**匹配信号权重：**
- 🔴 强信号：两条以上关系线同时出现问题
- 🔴 强信号：用户说"我不知道该选谁"
- 🟡 弱信号：同时只有两三个对象（可能只是正常的比较期）

### M10: 服从性测试过度/不足模式

**一句话定义：** 用户在关系中做服从性测试（让对方做一些小事来确认她的投入度）时，频率或力度不当——要么从不测试导致不知道对方是否投入，要么测试过度导致对方反感。

**触发条件：**
- 用户从不测试对方的服从性→对关系状态一无所知
- 或者用户频繁测试→让对方感到被操控
- 测试的内容与关系阶段不匹配

**常见表现：**
- "我不知道她到底对我有没有兴趣"（从不测试）
- "我让她做了很多事她都做了，但后来不理我了"（过度测试）
- "我让她帮我做了 X，她答应了——这说明什么？"

**背后原因：**
- M5（窗口判断）的实操工具：服从性测试是用来判断窗口的一种手段
- 不测试→信息盲区→你可能在一个没有窗口的关系中待了几个月
- 过度测试→对方感知你在利用她→反感→吸引力下降

**相关 Mental Model：** M5（窗口动态——测试是判断窗口的工具）、M4（投资循环——小测试=引导对方微投资）
**相关 Principle：** P05（施压减压交替）、P08（边界感）
**相关 Evidence：** Method 类型 Evidence 中的服从性测试方法

**可能动作：**
- 如果从未测试→开始做小型服从性测试（如让她帮你递东西、帮你查信息）
- 如果测试过度→停止测试，回到自然互动
- 原则：测试应该轻、自然、不被察觉——"能帮我拿一下吗"不是"你必须帮我"

**易混淆模式：**
- vs M01（需求感暴露）: 从不测试+频繁主动=需求感暴露
- vs E03（邀约推脱）: 邀约本身也是一种服从性测试

**匹配信号权重：**
- 🔴 强信号：用户说"我不知道她到底怎么想"且从未做过任何试探
- 🟡 弱信号：做了一两次服从性测试但不敢做更多

### M11: 框架废测失败模式

**一句话定义：** 面对对方的废测（shit-test），用户陷入解释/辩解模式，导致框架崩塌。

**触发条件：**
- 对方提出了一个带有测试性质的问题/挑战
- 用户认真解释了、道歉了、或开始证明自己
- 测试后对方的态度变得冷淡/不再尊重

**常见表现：**
- "她问我为什么昨天在那个地方，我解释了一大堆"
- "她说我是不是在追她，我赶紧否认了"
- "她质疑我某件事，我拼命证明自己"
- 用户感觉"被审问"却不知道这是测试

**背后原因：**
- M3（框架动态）：废测的本质是对方在测试你的框架强度
- 你的反应决定结果：不解释→框架维持；解释→框架弱化→对方试探升级
- 当你解释时，你不是在化解测试——你是在给她更多弹药
- 为什么解释会被视为弱？因为解释=你在征求她的认可

**相关 Mental Model：** M3（框架动态——废测是框架测试的核心形式）
**相关 Principle：** P01（关系动态）、P08（边界感）、反解释（E0737）
**相关 Evidence：** E0255, E0737, DM05

**可能动作：**
- 下一次遇到废测→不解释。用质疑动机、幽默化解、直接表达不适来回应
- 不是"回答她的问题"——是"不玩她的游戏"
- E0737 核心："不想聊就可以不讲，对方反而会更喜欢你"
- 训练识别废测的能力——不是每次质疑都是废测，但每次让你感觉"被审问"的很可能就是

**易混淆模式：**
- vs L02（框架沦陷）: 废测失败是框架沦陷的一个触发事件；框架沦陷是长期的后���

**匹配信号权重：**
- 🔴 强信号：面对质疑大段解释/证明/道歉
- 🔴 强信号：解释后对方态度反而更差
- 🟡 弱信号：对方只是一般性询问（不是测试）

### M12: 热冷交替测试模式

**一句话定义：** 对方通过主动切换热情和冷淡来测试用户的框架稳定性和需求感程度。

**触发条件：**
- 对方有时非常热情（主动联系、暧昧、表达好感）
- 然后突然变冷（不回复、冷淡、态度骤变）
- 用户因此产生强烈的情绪波动
- 这种热冷交替呈周期性或无明显原因

**常见表现：**
- "她上周对我特别好，主动约我，这周完全不理我了"
- "她聊着聊着突然就不回了，第二天又像没事一样找我"
- "她是不是在玩我？"
- 用户的情绪完全随对方的热冷而起伏

**背后原因：**
- 热冷交替本质上是一个**测试**——测试你是不是会跟着她的节奏走（M3）
- 如果她一热你就贴上去、一冷你就焦虑→她确认了你在她的框架里
- 如果她热你不热、她冷你不冷→你的框架比她稳→她反而会更投入
- 有时候不是对方故意测试——是她自己的情绪波动/多线操作的自然表现

**相关 Mental Model：** M3（框架动态——对你的框架测试）、M2（需求感传导——你的反应暴露需求感）
**相关 Principle：** P01（关系动态）、P03（需求感）、P08（边界感）
**相关 Evidence：** DM04, DM05

**可能动作：**
- 核心应对：不跟着她的节奏走——她热你不必更热，她冷你不必焦虑
- 保持你自己的节奏——你的生活不围绕她的热冷运转
- 如果你能做到不被她的热冷影响→她测试失败→你的框架更强→她反而会稳定
- 如果你做不到→她确认了她能控制你的情绪→框架沦陷的开始（L02）

**易混淆模式：**
- vs E10（备胎模式）: 备胎模式侧重于结构性判断（你是备胎）；热冷交替侧重于行为模式（对方在测试）
- vs L03（长期降温）: 热冷交替是波动的；长期降温是趋势性的单向下降

**匹配信号权重：**
- 🔴 强信号：2+ 次热冷循环+用户情绪被明显影响
- 🔴 强信号：用户说"她对我好的时候真好，不好的时候特别冷"
- 🟡 弱信号：偶尔的态度变化（可能只是她个人的情绪波动）

## 5. 长期阶段 Pattern

### L01: 一致性断裂模式

**一句话定义：** 用户在确定关系后行为发生显著变化（约会时自信→确定后变舔狗；追求时有趣→确定后无趣），导致吸引力持续流失。

**触发条件：**
- 曾经在某阶段表现良好（约会时/追求时）
- 确定关系后行为模式发生了显著变化
- 变化方向：从强→弱（自信→讨好、主动→被动、有趣→无趣）
- 对方态度因此持续下降

**常见表现：**
- "确定关系之前我什么都能聊，确定之后反而不知道说什么"
- "追她的时候她特别崇拜我，现在她觉得我没意思了"
- "我不知道怎么了，有了她之后就变了个人"
- "以前是她追我，现在是我追她"

**背后原因：**
- M6 核心因果链：行为变化→预期违背→"你不是我以为的那个人"→信任崩塌→吸引力流失→对方开始测试
- 根本原因：用户把"确定关系"当作"终点"——一旦到达终点就松懈了
- P04 的运作：一致性断裂是长期关系中吸引力流失的首要原因（DM08）
- E0084 的核心判断："你已经被她驯化了，只是你不知道"

**相关 Mental Model：** M6（一致性维持——最直接的实例化）、M8（关系衰减——M6 断裂→M8 衰减）
**相关 Principle：** P04（一致性是长期基础）、P06（投资差距）
**相关 Evidence：** DM08, E0084, E0727, E0318

**可能动作：**
- 核心：重建一致性不是"回到以前的表现"——是"从现在开始做真实的自己"
- 停止讨好和迎合——这是你偏离自己的根本原因
- 你需要的是回归，不是改变——回归到"确定关系前的你"
- 如果对方因为你回归真实而离开→这段关系本来就不建立在真实的你之上

**易混淆模式：**
- vs L02（框架沦陷）: 一致性断裂导致框架沦陷——它们是因果而非并列
- vs L04（被驯化）: 被驯化是一致性断裂的极端结果
- vs M04（约会后降温）: 约会后降温发生在暧昧/约会阶段；一致性断裂发生在确定关系后的长期阶段

**匹配信号权重：**
- 🔴 强信号：以"确定关系"为明确分水岭的行为变化
- 🔴 强信号：从前主动有趣自信→现在被动讨好焦虑
- 🔴 强信号：用户说"不知道什么时候开始就变了"

---

### L02: 框架沦陷模式

**一句话定义：** 用户的框架在长期关系中逐渐被侵蚀——从被尊重的上位者变成被对方主导的下位者。

**触发条件：**
- 曾处于上位的框架位置
- 现在开始迎合对方、不敢表达不同意见、不敢拒绝
- 被对方的节奏和情绪带着走
- 对方对你的尊重度持续下降
- 这是渐进性的——不是一次事件

**常见表现：**
- "以前她还挺尊重我的，现在越来越不拿我当回事"
- "我都不敢跟她说我不舒服的事，怕她生气"
- "她让我改什么我就改什么"
- "我发现自己做的决定越来越少了，都是她在做"
- "每次冲突都是我让步"

**背后原因：**
- M3 核心因果链：每一次让步→对方测试你的底线→确认可以继续推→下一次更过分
- 框架沦陷不是突然崩塌的——它是逐渐侵蚀的。从"偶尔让步"到"总是让步"到"没有立场"
- 底层机制：框架=谁制定规则。当你不再制定规则（或你的规则不被尊重）→你就是下位
- E0084："你已经被她驯化了，只是你不知道"

**相关 Mental Model：** M3（框架动态——渐进侵蚀）、M8（关系衰减——框架沦陷→衰减加速）
**相关 Principle：** P01（关系动态决定吸引力）、P08（边界感维持框架）
**相关 Evidence：** DM05, E0084, E0016, E0234, E0719

**可能动作：**
- 第一步：识别当前状态——你现在是"有冲突能力但选择不冲突"还是"没有冲突能力被迫服软"（E0683）？前者是选择，后者是沦陷
- 第二步：选择一个边界问题→明确说"不"→观察反应
- 第三步：如果对方因此生气/威胁→说明沦陷程度比你想象的深
- 核心原则：修复框架可能需要一次冲突——不被接受的"不"只是一句话，被接受的"不"才是框架
- 最坏情况：对方不接受你重建框架→关系可能结束（但一个你不被尊重的关系，结束也许不是坏事）

**易混淆模式：**
- vs L01（一致性断裂）: 一致性断裂是框架沦陷的常见前因
- vs L04（被驯化）: 被驯化是框架沦陷的极端结果——L04 侧重结果，L02 侧重过程
- vs M11（废测失败）: 废测失败是单次事件；框架沦陷是长期过程

**匹配信号权重：**
- 🔴 强信号：不敢表达不同意见、不敢拒绝、总是你让步
- 🔴 强信号：对方对你的态度从尊重变成轻视
- 🔴 强信号：你做的决定越来越少
- 🟡 弱信号：偶尔的迁就（正常的伴侣互动）

---

### L03: 关系慢性降温模式

**一句话定义：** 确定关系后的长期关系中，热度、投入度、吸引力持续缓慢下降，双方或一方逐渐失去兴趣。

**触发条件：**
- 已确定关系数月到数年
- 热度呈持续性缓慢下降（不是断崖式）
- 亲密度、沟通频次、性趣都在下降
- 但双方没有重大冲突——是"平淡下来"的感觉

**常见表现：**
- "我们很久没有像以前那样聊天了"
- "感觉变成了室友"
- "性生活显著减少"
- "她不再像以前那样在乎我了"
- "我不知道这算不算正常"

**背后原因：**
- M8 核心因果链：不同类型的入口汇合到"对方感知已完全得到你"
- 慢性降温的独特之处：不是单一原因导致的——是 M1（吸引力自然衰减）+ M2（日常需求感暴露）+ M6（一致性在长尺度上的逐渐偏离）的复合效应
- 关键机制：可得性过度（E0739）——当你完全可预测、完全可控、完全围绕对方运转时，吸引力就蒸发了
- 不像 L01（一致性断裂）有明显分水岭，慢性降温是"不知不觉"的

**相关 Mental Model：** M8（关系衰减——核心模型）、M2（需求感在长期中的累积效应）、M1（吸引力自然衰减）
**相关 Principle：** P04（一致性）、P03（需求感）、P06（投资差距）
**相关 Evidence：** DM08, E0739, E0318, E0528

**可能动作：**
- 判断衰减程度：如果对方对你还有敬畏感→可修复；如果敬畏感消失→接近临界点
- 重新制造不确定性——不是出轨或若即若离，是让对方感受到"你还有她不知道的一面"
- 控制可得性："永远不能让女性觉得完全得到了你"（E0739）
- 引导对方投资——重新激活 M4 的健康循环

**易混淆模式：**
- vs L01（一致性断裂）: 一致性断裂有明确的断裂点；慢性降温是没有任何单一事件的无感下降
- vs M02（投资下降）: M02 发生在暧昧/约会阶段；L03 发生在确定关系后的长期阶段

**匹配信号权重：**
- 🔴 强信号：长期关系（6 个月+）+ 多维度持续下降
- 🔴 强信号：没有明显原因的"就这样淡了"
- 🟡 弱信号：短期低潮（所有长期关系都有起伏）

### L04: 被驯化模式

**一句话定义：** 用户在关系中完全丧失了自我边界和独立性——被要求改变就改变，被要求妥协就妥协，最终成为一个没有内核的"听话的人"。

**触发条件：**
- 对方提出"希望你改变"的要求
- 用户真的改变了
- 改变后对方的尊重度下降（而不是上升）
- 用户继续被要求更多的改变
- 形成"要求→改变→尊重度下降→更多要求"的恶性循环

**常见表现：**
- "她说希望我少跟朋友出去，我就不去了"
- "她说我穿得不好看，我就换了风格"
- "她希望我换个工作，我在考虑了"
- "我改了很多，但她好像越来越不满意"
- "我不知道我还有什么没改的"

**背后原因：**
- M3（框架）和 M8（衰减）的交叉："女性真正喜欢的是她感觉能改变但永远改变不了的男人"（E0719）
- 每一次你真的改变→你都在证明"你可以被我改变"→她失去对你的敬畏
- 悖论：她不满意→要求你改变→你改变→她更加不满意。因为"你愿意为她改变"这件事本身就降低了你的价值
- E0084：改的那一刻吸引力就开始降低

**相关 Mental Model：** M3（框架动态——框架被彻底摧毁）、M8（关系衰减——被驯化后的不可逆衰减）
**相关 Principle：** P08（边界感）、P07（自我价值感）、P01（关系动态）
**相关 Evidence：** E0084, E0719, DM08, E0024（周士民案例）

**可能动作：**
- 核心：停止被驯化——不是说"我以后不改了"，而是"我不需要通过改变自己来满足你的期待"
- 关键区分：合理的改变（双方共同成长）vs 被驯化（单方面为了取悦而改变）
- 如果已经被驯化较深→恢复框架需要"不回应她的改变要求"+"重建独立的自我"
- 最终底线：如果你不能在这个关系中做自己→这个关系不适合你

**易混淆模式：**
- vs L02（框架沦陷）: 被驯化是框架沦陷的极端临床形式——L02 描述过程，L04 描述结果
- vs L01（一致性断裂）: 一致性断裂是 L04 的前身——断裂后开始迎合，迎合变成被驯化

**匹配信号权重：**
- 🔴 强信号：对方要求改变且你真的改变了→重复 2+ 次
- 🔴 强信号：你改变后她不满意反而更多
- 🔴 强信号：你开始按照她的标准定义自己的人生

---

### L05: 可得性过度模式

**一句话定义：** 用户让对方感觉"已经完全得到了他"——完全可预测、完全可控、完全围绕对方运转，导致吸引力持续流失。

**触发条件：**
- 长期关系中
- 用户的行为完全可预测（每天固定联系、固定内容、固定模式）
- 用户没有独立于关系之外的精彩生活
- 对方不再有"抓住"或"失去"的感觉
- 关系变得完全安全但完全无趣

**常见表现：**
- "我们每天都会联系，但聊的内容都一样"
- "她好像对我不再有兴趣了"
- "我们之间没有任何惊喜"
- "我的生活就是上班和陪她"

**背后原因：**
- E0739 核心：永远不能让女性觉得完全得到了你
- M8 核心机制：吸引力需要一定的"不确定性"和"挑战"来维持。当你变成一个完全可预测的人→对方不需要再为你投入任何精力→M4 反向
- E0528："女人就喜欢让她没有安全感的男人"——不是说要让对方担心出轨，而是说关系动态层面的"你还有别的选择""你的世界不止她一个人"
- 可得性过度和一致性不矛盾——你可以保持一致性的同时不完全可得（一致性=你的行为模式稳定；可得性=你有没有独立于关系之外的自我）

**相关 Mental Model：** M8（关系衰减）、M4（投资循环——对方不需要投资因为已经"得到"了）
**相关 Principle：** P06（投资差距）、P09（零压力状态的另一面——太安全=太无聊）
**相关 Evidence：** E0739, E0528, DM08

**可能动作：**
- 重新建立独立于关系的自我——不是出轨，是重新有自己的爱好/事业/社交
- 制造适度的不可预测性——不是忽冷忽热，是让对方看到你的生活不止她
- 让对方重新需要"争取"你的注意力——不是你说"你来争取我"，而是你自然有更丰富的生活
- 控制可得性≠若即若离——前者是"我有我的节奏"；后者是"我在故意吊着你"

**易混淆模式：**
- vs L03（关系慢性降温）: 可得性过度是慢性降温的原因之一
- vs L01（一致性断裂）: 一致性断裂是行为变化导致吸引流失；可得性过度是行为不变（过于稳定）导致吸引流失

**匹配信号权重：**
- 🔴 强信号：你的生活完全围绕对方运转
- 🔴 强信号：双方都感觉"没什么新鲜感了"
- 🔴 强信号：你没有任何对方不知道的活动/社交/兴趣

---

### L06: 敬畏感丧失模式

**一句话定义：** 对方对用户不再有敬畏/尊重——"过度甜蜜但缺乏敬畏"（DM08）——标志着关系进入了关键危险区。

**触发条件：**
- 长期关系中
- 对方对你态度很好（甜蜜、温柔、不说难听话）
- 但你不被尊重——你的意见不被重视、你的边界被试探、你不再有"权威"
- DM08 核心判断："过犹不及"——过度甜蜜但没有敬畏

**常见表现：**
- "她对我挺好的，但有时候我觉得她不太尊重我"
- "我说什么她都会说好，但从来不照做"
- "她不会跟我吵架，但我感觉我在她心里没分量"
- "她有什么事都不跟我商量"

**背后原因：**
- M8 的临界点：甜蜜 vs 敬畏——健康的关系需要两者兼备。"过度甜蜜但缺乏敬畏"是失衡信号
- 敬畏感的来源：对方觉得你不可被随意对待、你的规则会被执行、失去你会是一个真正的损失
- 敬畏感丧失的过程：框架沦陷（L02）+ 被驯化（L04）+ 可得性过度（L05）→ 对方不再觉得需要"小心对待"你
- 这个时刻很重要——它可能是关系从"可以修复"到"不可逆"的转折点

**相关 Mental Model：** M8（关系衰减——敬畏感丧失是临界点标志）、M3（框架动态——敬畏是框架的最终防线）
**相关 Principle：** P01（关系动态）、P08（边界感）
**相关 Evidence：** DM08, E0084

**可能动作：**
- 判断敬畏度：测试——你做一件需要坚持边界的事→看她的反应
- 如果她不在乎你的坚持→敬畏感可能已经基本丧失
- 重建敬畏比重建吸引更难——因为敬畏是综合性的（框架+吸引力+边界的综合感知）
- 如果敬畏感已丧失→你可能需要一次明确的"框架重置"（可能涉及冲突）

**易混淆模式：**
- vs L02（框架沦陷）: 敬畏感丧失是框架沦陷的最终结果
- vs L03（关系慢性降温）: 慢性降温侧重热度下降；敬畏丧失侧重尊重度下降

**匹配信号权重：**
- 🔴 强信号：你说话不算数但对方不在乎
- 🔴 强信号：对方自己做重大决定不跟你商量
- 🔴 强信号：你表达了不满但对方当耳旁风

---

### L07: 社交地位/价值逆转模式

**一句话定义：** 在关系中，拥有客观高价值的一方因为行为线索弱而处于下位，而客观价值低的一方因为行为线索强而处于上位。

**触发条件：**
- 用户客观价值不错（财富/能力/外貌等）
- 但在关系中处于下位
- 对方在关系中占主导
- 外在评价和关系内地位严重不匹配

**常见表现：**
- "我什么条件都比他好，但她就是向着他"
- "我赚多少钱她好像都不在乎"
- "她父母/朋友都觉得我挺好的，但她对我一般"
- 用户的困惑：为什么客观条件好却没被珍惜

**背后原因：**
- M1+M3 的核心洞察：P01——社交地位决定吸引力，不是外在数值
- E0233（PG One vs 贾乃亮）：贾乃亮的客观条件远好于 PG One，但 PG One 传递的是强者行为线索
- E0237（C罗案例）：C罗作为顶级球星，在与前妻的关系中处于服从地位
- 机制：女性对"强"的感知来自关系动态（谁主导、谁被尊重、谁的规则被执行），不是外在数值
- 外在价值≠价值感（P07）

**相关 Mental Model：** M1（吸引力动态——行为线索 > 客观数值）、M3（框架动态——谁在关系中主导）
**相关 Principle：** P01（关系动态决定吸引力）、P07（自我价值感独立于外在价值）
**相关 Evidence：** E0233, E0237, E0024（周士民）, E0130（小明剑魔）

**可能动作：**
- 核心认知转变：不是"我条件这么好她为什么不珍惜我"→是"我在关系中传递了什么行为线索"
- 检查：你在关系中是否在讨好？是否不敢表达？是否被对方的情绪完全控制？
- 与 L02 重叠——行动方向参照框架沦陷的修复方案

**易混淆模式：**
- vs L02（框架沦陷）: 框架沦陷是普遍模式；社交地位/价值逆转侧重于"客观条件好但在关系中处于下位"这个特定矛盾
- vs X03（不配得感）: 不配得感是你觉得自己配不上；价值逆转是外在条件好但内在位置低

**匹配信号权重：**
- 🔴 强信号：客观条件明显不错但在关系中不被尊重
- 🔴 强信号：用户困惑"为什么她不在乎我的条件"

---

### L08: 长期关系分手/终结模式

**一句话定义：** 长期关系在经历了多种衰减因素（一致性断裂/框架沦陷/被驯化/第三方）叠加后，抵达了不可挽回的终点。

**触发条件：**
- 长期关系（通常以年为单位）
- 出现了明确的结束信号（对方提出分手/长期冷战/一方已移情）
- 修复努力无效
- 核心判断：是否已过临界点？

**常见表现：**
- "她说她不爱我了"
- "我们分手了，但我想挽回"
- "她已经和别人在一起了"
- "我们冷战了一个月了"

**背后原因：**
- M8 的终局：所有衰减路径的汇合点
- 不是单一原因——通常是 3+ 个 Mental Model 的断裂同时发生
- 关键判断：是否还有修复可能？→看对方是否还有任何投入（主动联系/关心/嫉妒等）
- 如果对方完全无感→已过临界点，不可逆

**相关 Mental Model：** M8（关系衰减——终局阶段）
**相关 Principle：** P07（自我价值感——分手后的自我重建）
**相关 Evidence：** DM08, E0130

**可能动作：**
- 核心判断：有没有投入残留？（对方还关心你吗？还嫉妒吗？还会主动联系吗？）
- 如果有投入残留→不是"追回来"→是"停止现在的错误行为+重建吸引"
- 如果完全无投入→接受结局。你需要的不是挽回技巧，是叙事重构（I4）
- 不追溯"为什么"→如果你真的想知道为什么，看 L01-L07

**易混淆模式：**
- vs L03（关系慢性降温）: L03 是可修复的阶段；L08 是不可逆的终点

**匹配信号权重：**
- 🔴 强信号：对方明确表达结束
- 🔴 强信号：对方已开始新关系
- 🟡 弱信号：冷战/暂时分开（可能只是危机，不是终结）

---

### L09: 出轨/越界容忍模式

**一句话定义：** 对方出轨或严重越界，用户因为害怕失去而选择容忍，导致底线崩溃和持续被践踏。

**触发条件：**
- 关系中出现了对方的严重越界行为
- 用户选择了容忍/原谅但不设边界
- 对方没有真正改变，继续越界
- 用户在"原谅→再次受伤→继续原谅"中循环

**常见表现：**
- "她出轨了我原谅了她，但后来又..."
- "我知道她在跟别人暧昧，但我不敢说"
- "我怕失去她所以什么都忍了"

**背后原因：**
- M3（框架）的终极测试：越界后的容忍=告诉对方"你可以越界，没有后果"
- DM05 判断："表现出稀缺和讨好→对方大概率会出轨"；"传递'出轨就再见'框架→对方大概率不会出轨"
- 这不是"她会不会改"的问题——是"你是否设置了边界"的问题
- 容忍=你在教对方"我不值得被认真对待"

**相关 Mental Model：** M3（框架动态——边界是框架的最后防线）、M8（关系衰减——越界容忍是衰减的加速器）
**相关 Principle：** P08（边界感维持框架）、P01（关系动态）
**相关 Evidence：** DM05, E0130

**可能动作：**
- 边界从第一次越界就必须设立——不是惩罚对方，是保护自己
- 如果已经多次容忍→你的边界已经形同虚设→修复难度极高
- 不是"她值不值得被原谅"→是"你值不值得被尊重"

**易混淆模式：**
- vs L02（框架沦陷）: 框架沦陷是渐进性的；出轨容忍是事件触发性的
- vs L08（分手/终结）: L09 是 L08 的一种典型前置

**匹配信号权重：**
- 🔴 强信号：严重越界 + 容忍 + 继续越界
- 🔴 强信号：你因为害怕失去而不敢表达不适

---

### L10: 强框架长期高位模式

**一句话定义：** 在长期关系中持续维持强框架和高吸引力——对方保持敬畏、尊重和持续投入。（正面模式）

**触发条件：**
- 长期关系中
- 对方持续尊重你的边界
- 你对对方保持吸引力
- 关系动态健康（不是"一方过高一方太低"）

**常见表现：**
- "这么多年了她还是很尊重我"
- "我们之间互相尊重、互有空间"
- "她不会随便对待我"
- 这是健康长期关系的理想状态

**背后原因：**
- 多个 Mental Model 同时正向运作：M1（吸引力持续维持）、M3（框架稳健）、M4（双向投资平衡）、M6（一致性不断裂）
- E0535 核心："强者不需要咄咄逼人也可以建立权威——这种能量润物细无声却拥有绝对权威"
- E0683："有冲突能力但选择不冲突"

**相关 Mental Model：** M3（框架动态——长期稳健）、M6（一致性维持）、M4（投资循环——双向投资健康）
**相关 Principle：** P01（关系动态）、P08（边界感）、P09（零压力）
**相关 Evidence：** E0535, E0590, DM05

**可能动作：**
- 这是一个正面模式——不是什么都需要改变
- 保持方向：维持自己的独立性、维持边界、维持吸引力
- 警惕信号：如果对方开始试探边界→可能进入 L02

**易混淆模式：**
- vs X04（零压力成功）: X04 适用于任何阶段；L10 是长期阶段的正向模式

**匹配信号权重：**
- 🔴 强信号：对方持续尊重你、保持投入、有敬畏
- 🔴 强信号：你觉得这段关系让你变得更好而不是更焦虑

## 6. 跨阶段 Pattern

### X01: 自欺驱动模式

**一句话定义：** 用户用一套叙事掩盖真实动机或真实状态，声称是 A 但行为指向 B——最常见于"我真的很喜欢她"但行为是焦虑性追逐。

**触发条件：**
- 用户的自我叙事和实际行为之间存在明显矛盾
- 用户在反复被指出后仍坚持原来的叙事
- 用户的判断被情绪（饥饿/孤独/焦虑）严重扭曲

**常见表现：**
- "我很喜欢她"——但对她的了解很少，对她的缺点视而不见
- "我们很合适"——但没有对方给出兴趣信号的证据
- "我只是想对她好"——但行为是追逐和证明自己
- "我觉得她在考验我"——但对方实际上从未给出 IOI
- 用户不愿意接受与自己叙事矛盾的判断

**背后原因：**
- 核心因果链（来自 D1c 自欺检测）：认知失调→用户需要维持"我是一个正常追求者"的自我形象→编造叙事掩盖"我饿了太久"的真相
- E0017：用户说"我很想追她"→Mikey 判断"你饿了太久了"
- 饥饿心态会让一个人把任何信号都解读为正面信号，把拒绝都解读为考验
- 这不是道德问题——这是认知问题。用户在骗自己，不是在骗你

**相关 Mental Model：** M2（需求感传导——自欺常常是需求感的认知表现）、X03（不配得感——自欺和配得感紧密相关）
**相关 Principle：** P07（自我价值感）、P09（零压力状态——执着导致判断扭曲）
**相关 Evidence：** E0017, E0087, DM04, DM05

**可能动作：**
- 核心：不是说服用户"你错了"——是指出行为与叙事的矛盾
- 叙事重构（I4）："如果你是你自己的朋友，你会怎么评价你现在做的事？"
- 追问行为而非感受："她最近一次主动找你是什么时候？"
- 如果用户坚持自欺→标注自欺标记，但尊重用户的选择——不是所有人在所有时刻都准备好面对真相

**易混淆模式：**
- vs X06（认知障碍）: 认知障碍是"我怎么看都看不懂"；自欺是"我其实知道但不愿意承认"
- vs M01（需求感暴露）: 需求感暴露是行为层面的判断；自欺是认知层面的判断

**匹配信号权重：**
- 🔴 强信号：用户叙事和行为之间存在明显矛盾
- 🔴 强信号：用户被指出矛盾后仍然坚持原叙事
- 🔴 强信号：用户的所有解读都偏向"正面"方向（系统性乐观偏差）

---

### X02: 泡学中毒模式

**一句话定义：** 用户已学习大量 PUA/把妹理论，导致行为僵硬——不是在自然互动，是在"执行战术"。

**触发条件：**
- 用户有 PUA/把妹理论学习经历
- 互动中行为不自然——每条回复都像在套公式
- 过度关注"技术正确"而非"自然流畅"
- 因为"按照理论该这样做"而做出违背直觉的行为

**常见表现：**
- "理论上我应该先推再拉，但我不知道该说什么"
- "我按照框架理论做了，为什么她还是不理我"
- "我用了 X 技巧，但效果不好"
- 每条回复都在计算"这样做对不对"

**背后原因：**
- M7 的反面：技术不能替代状态。当你背着一个"推拉"的公式去聊天时——你已经不自然了
- P02：紧张/执行/计算→传递弱行为线索。对方感知到"这个人在背台词"
- E0112 案例核心：天赋高但理论中毒，死守高框架不愿给台阶→失去灵活性和自然性
- 理论是给"不知道怎么走"的人的地图——当你开始走路时还盯着地图就撞树了

**相关 Mental Model：** M1（吸引力动态——技术不能创造吸引）、M7（升级推进——自然的推进和公式化的推进是两回事）
**相关 Principle：** P10（吸引先于技术）、P02（状态大于内容）、P09（零压力）
**相关 Evidence：** E0112, E0316, E0521

**可能动作：**
- 停止学习新理论——你已经学够了
- 下一个阶段不是"学更多"→是"用更少"。让理论内化，然后忘掉理论
- 练习：不要想"该做什么"，想"我想做什么"——从自然的欲望出发
- 如果你发现自己在计算"推拉比例"→停下来，回到最简单的"真诚聊天"

**易混淆模式：**
- vs M07（技术依赖陷阱）: 泡学中毒是技术依赖的进阶版——不是"用技术"，是"被技术用"
- vs X01（自欺驱动）: 泡学中毒也可以是一种自欺——"只要我用对方法，就会成功"

**匹配信号权重：**
- 🔴 强信号：用户用理论术语描述日常互动
- 🔴 强信号：用户说"按照理论该 X 但我 Y 了"
- 🟡 弱信号：正常的学习期过渡

---

### X03: 不配得感模式

**一句话定义：** 用户拥有客观价值（能力/资源/外貌），但内心深处不相信自己"配得上"好的关系/好的对待。

**触发条件：**
- 用户客观条件不错（或至少不差）
- 但在关系中表现为低位——讨好、不敢提要求、不敢表达不满
- 被对方善待时感到不安或"欠她的"
- 觉得需要"证明"自己的价值才能被喜欢

**常见表现：**
- "我总觉得我配不上她"
- "她对我这么好，我觉得自己欠她的"
- "我怕她发现其实我没那么好"
- "我要先变得更好才有资格去追她"
- E0357 案例：朋友因为女友对他八分好而他只有三分喜欢而感到内疚

**背后原因：**
- P07 核心：价值 ≠ 价值感。你可能有很高的价值（财富/能力）但极低的价值感
- 底层机制：把自我价值建立在外在反馈上→对方的反应决定你的自我感觉→你永远处于匮乏状态
- E0357："你不需要感到愧疚，她喜欢你是她的选择"
- 不配得感在关系中表现为：不敢要、不敢争、不敢走——恰好是 M3（框架弱）的内在根源

**相关 Mental Model：** M3（框架动态——不配得感是框架弱的根因）、M1（吸引力动态——讨好姿态传递弱行为线索）
**相关 Principle：** P07（自我价值感独立于外在价值）、P01（关系动态）
**相关 Evidence：** E0357, E0021, E0035, E0096, E0097

**可能动作：**
- 核心认知重构（I4）：区分"我是什么样的人"（价值）和"我觉得我是什么样的人"（价值感）
- 不是"先变得更好再去追"→"先接受现在的自己就是值得被喜欢的"
- "真正的自信和你有没有钱有没有外形无关"（P07）——这句话的价值在此刻最明显
- 练习：下一次想说"我不配"的时候→改成"她的选择说明她觉得我值得"

**易混淆模式：**
- vs E04（搭讪焦虑）: 搭讪焦虑是情境性的；不配得感是持续性的自我认知
- vs X01（自欺驱动）: 不配得感可能导致自欺（"我不够好所以我要更努力=更追逐"）

**匹配信号权重：**
- 🔴 强信号：客观条件不错但在关系中感到"配不上"
- 🔴 强信号："我要先做到 X 才有资格 Y"的思维模式
- 🔴 强信号：被善待时感到不安

---

### X04: 零压力成功模式

**一句话定义：** 用户在放松、不执着于结果的状态下，自然而然地达到了正面的关系进展。（正面模式）

**触发条件：**
- 用户不执着于某个特定结果
- 用户处于放松、自然的状态
- 行为来自直觉而不是计算
- 结果（约会/升级/关系发展）比预期好

**常见表现：**
- "我那天也没多想，就随便聊了聊，结果她特别主动"
- "本来没抱希望，结果特别好"
- "越不在意的，反而越顺利"
- E0326 案例：Mikey 小时候参加运动会，没有心理压力放开跑反而跑了第一名

**背后原因：**
- P09 核心机制：不执着于结果→行为自然→传递强行为线索→吸引力自然产生
- 反向证明：不是"零压力导致成功"——是"压力导致变形→变形导致失败"。零压力只是回到基线
- 零压力≠不准备——是"准备好"然后"不执着于结果"
- 这是 M1 正反馈的健康启动方式

**相关 Mental Model：** M1（吸引力动态——正反馈循环的自然启动），M7（升级推进——自然的推进）
**相关 Principle：** P09（零压力状态最佳）、P07（自我价值感）
**相关 Evidence：** E0326, E0007, E0061, E0108

**可能动作：**
- 这是一个正面模式——不需要干预
- 关键：如何复制？不是"每次都让自己零压力"（这本身就是压力）→是"把注意力从结果转移到体验"
- 如果你问"我怎么才能做到零压力"→你已经有了压力

**易混淆模式：**
- vs E11（小白速成）: E11 是新手零压力（无知者无畏）；X04 是有经验后的零压力
- vs L10（强框架长期高位）: L10 是长期阶段的正面模式；X04 可以发生在任何阶段

**匹配信号权重：**
- 🔴 强信号：用户说"我没多想/没抱希望/随便聊聊"
- 🔴 强信号：结果比预期显著好

---

### X05: 认知重构/视角翻转模式

**一句话定义：** 用户（或 Mikey 指导下）从完全不同的视角重新审视自己的处境，从而打破原有的认知局限——这是一个从"诊断"到"领悟"的转折点。

**触发条件：**
- 用户处于困惑/痛苦中——"为什么会这样"
- 原来看问题的方式导致无力感
- 需要一个新的解释框架来打破僵局
- 常见触发：Mikey 的一句反直觉判断

**常见表现：**
- "你这么一说我突然明白了"
- "我从来没这样想过"
- 典型触发语句：
  - "你喜欢一个人的时候会做什么？看看她有没有对你做这些"（E0028）
  - "你被拒绝了——但她了解完整的你吗？一场一个小时的面谈能决定你的一切吗？"（E0214）
  - "老板不会害怕员工冷场"（E0081）
  - "你怕失去她——你给她的答案赋予了太多意义"

**背后原因：**
- I4（叙事重构）的核心操作：改变用户对处境的解释框架
- 机制：用户的痛苦不是来自"事实"，而是来自"对事实的解释"
- 视角翻转→认知重构→行为自然改变（不需要强迫）
- 这是 Mikey 体系中最深层、最具教育价值的干预

**相关 Mental Model：** 间接涉及所有 Mental Model——认知重构是改变用户看待 Mental Model 的方式
**相关 Principle：** P07（自我价值感）、P09（零压力）
**相关 Evidence：** E0028, E0214, E0081, I4

**可能动作：**
- 这是一个"中间状态"——认知重构后需要落实为具体行动（Gate 5）
- 不是所有案例都需要认知重构——只在用户的认知框架本身就是问题时使用

**易混淆模式：**
- vs X01（自欺驱动）: 自欺是从错误的认知中获益（拒绝面对）；认知重构是真实地看到新的视角

**匹配信号权重：**
- 🔴 强信号：用户说"我从来没这样想过"或类似的顿悟时刻
- 🟡 弱信号：用户需要新的视角但还没有找到

---

### X06: 认知障碍/信息盲区模式

**一句话定义：** 用户缺乏对自己关系的准确阅读能力——对关键信号的解读与事实严重偏离。

**触发条件：**
- 用户对关系的解读与客观行为数据矛盾
- 用户无法识别 IOI 或错误地解读为 IOI
- 用户的判断一直被自己的情绪/欲望扭曲
- 信息充足但用户就是读不准

**常见表现：**
- "我觉得她喜欢我"——但对方从未主动发起过对话
- "她说忙是真的忙"——但已连续推脱 4 次
- 用户对"她是不是喜欢我"的判断反复摇摆
- 用户依赖于对方的"话"（"她说她不喜欢主动"）而非"行为"（她从没主动过）

**背后原因：**
- P2（信号分解）能力的缺失：用户无法分离表沟通和潜沟通——把礼貌当 IOI，把语言当信号，把行为忽略
- P3（模式识别）能力的缺失：看到信号但不会匹配到已有模式
- E0517/E0661 核心：许多人捕捉不到社交动态，对方上钩了也不知道
- 这是"Expertise Model P1+P2 层的底层能力缺失"在 Pattern 层面的体现

**相关 Mental Model：** M5（窗口动态——窗口识别）、M1（吸引力判断）、M2（需求感暴露的自我觉察）
**相关 Principle：** P02（潜沟通）、P10（吸引判断）
**相关 Evidence：** E0517, E0661, DM01, E0378

**可能动作：**
- 不直接给答案——帮助用户发展自己的"信号分解"能力
- 追问行为：不看她说"什么"，看她说"什么"的时候做了"什么"
- 教用户区分：表沟通（话）和潜沟通（行为线索）
- 这是长期能力建设——不是一次咨询能解决的问题

**易混淆模式：**
- vs X01（自欺驱动）: 自欺是"知道但不愿承认"；认知障碍是"真的看不出来"
- vs E08（礼貌性互动）: E08 是对方的具体行为模式；X06 是用户解读能力的系统性缺陷

**匹配信号权重：**
- 🔴 强信号：用户的判断反复摇摆且每次判断都依赖对方的言语而非行为
- 🔴 强信号：用户对一段明显没有希望的关系抱有希望

### X07: 内在限制解除模式

**一句话定义：** 用户的内在心理障碍（过往创伤/童年经历/社会条件化）导致在关系中表现受限，突破这些限制后状态发生显著改变。

**触发条件：**
- 用户的限制不是技术性的（不是"不会"）而是心理性的（"不敢"）
- 有可追溯的内在原因（自卑经历/创伤事件/社会条件化）
- 突破后表现和结果发生显著变化

**常见表现：**
- E0268 案例：因为小时候牙黄被嘲笑→长大后牙已变白→和女生聊天仍本能地不敢笑
- E0225 案例：极度社恐学员→内在限制解除后状态显著改变称"开悟"
- 用户说"我知道该怎么做，但就是做不到"
- "我的脑子告诉我要放松，但我的身体不听使唤"

**背后原因：**
- 这是 M1（吸引力）、M6（一致性）、P07（自我价值感）、P09（零压力）在心理层面的交汇
- 机制：内在限制→行为线索变形→传递弱行为线索→吸引力不建立→自我证实"我果然不行"
- 突破关键：不是"更多技术"或"更多鼓励"→是在安全环境中体验"原来我可以做到"

**相关 Mental Model：** M1（吸引力动态——内在限制解除后行为线索自动变强）、M6（一致性——解除后自然一致）
**相关 Principle：** P07（自我价值感）、P09（零压力状态）
**相关 Evidence：** E0225, E0268, E0101

**可能动作：**
- 不靠"鼓励"——你不是需要被告诉"你很棒"，你需要自己感受到"我能做到"
- 小步突破：不是"从社恐变社牛"→是"今天跟一个陌生人打招呼"
- 每次小成功→自我证实→行为线索改善→正反馈启动（M1 正向）

**易混淆模式：**
- vs E04（搭讪焦虑）: 搭讪焦虑是情境性的焦虑；内在限制是更深层的心理障碍
- vs X03（不配得感）: 不配得感是价值观层面的"我不配"；内在限制是行为层面的"我做不了"

**匹配信号权重：**
- 🔴 强信号：用户自述"我知道该做什么但就是做不到"
- 🔴 强信号：有限制与特定过往经历之间的可追溯联系
- 🔴 强信号：限制不是在特定场景出现，而是跨场景的普遍模式

Pattern 之间存在因果和时序关系。以下是关键转化路径：

```
早期阶段：

  E01(搭讪后失联) → E09(搭讪循环失败)  [个案→系统性失败]

  E02(聊天降温) → M01(需求感暴露)     [降温原因明确化]
  E08/E10 → M02(投资下降)              [不投入升级为退出信号]
  M01(需求感) → M02(投资下降)          [暴露需求→对方退出]
  M01(需求感) → M03(窗口下降)          [暴露需求→窗口关闭]

  L01(一致性断裂) → L02(框架沦陷) → L04(被驯化) → L06(敬畏丧失) → L08(终结)

  E11(小白速成) → X04(零压力成功) → L10(强框架长期高位)
```

| Pattern 组合 | 共存频率 | 判断 |

| E02(聊天降温) + E10(备胎模式) | 高 | 聊天降温可能演变为备胎关系 |

### 7.3 Pattern 互斥关系

某些 Pattern 在逻辑上不能同时成立：

| Pattern A | Pattern B | 为何互斥 |
|-----------|-----------|---------|

| E10(备胎模式) | M03(窗口下降) | 备胎=窗口从未打开；窗口下降=曾打开过 |
| X04(零压力成功) | E04(搭讪焦虑) | 焦虑和零压力是对立状态 |

## 8. 与 Decision Flow Gate 1 集成

### 8.1 Gate 1 匹配流程

```
用户案例描述
    │
    ▼
┌─────────────────────────────────────────┐
│ 1. 关系阶段识别                          │
│    陌生/熟悉/暧昧/亲密/长期               │
│    → 确定候选 Pattern 池（E/M/L/X）       │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ 2. 关键信号提取                          │
│    从用户描述中提取关键信号（见各 Pattern   │
│    的「强信号」列表）                      │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ 3. 相似度匹配                            │
│    与候选 Pattern 做关键信号重叠度评估      │
│    → 高匹配（>80% 信号重叠）→ 快速通道    │
│    → 混合匹配（多 Pattern 各匹配一部分）    │
│    → 低匹配（无 Pattern 匹配）→ 深度通道  │
└─────────────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────────────┐
│ 4. 易混淆模式排除                        │
│    检查候选 Pattern 的「易混淆模式」       │
│    → 确认匹配的 Pattern 是否正确           │
│    → 如果不确定→标注并走标准通道           │
└─────────────────────────────────────────┘
```

### 8.2 匹配度计算逻辑

不进行精确的数值计算——采用信号权重评估：

- **匹配度 = 高**：3+ 个强信号出现
- **匹配度 = 中高**：2 个强信号 + 2+ 个弱信号
- **匹配度 = 中**：1 个强信号 + 部分弱信号
- **匹配度 = 低**：仅有弱信号，或信号不典型

### 8.3 Gate 1 输出格式

匹配完成后，输出：

```
Pattern 判断：[PAT-XX] / [PAT-XX + PAT-YY 混合] / [低匹配-标注不确定性]
匹配度：[高/中高/中/低]
关键依据：[3 个最高权重信号]
差异点：[与标准 Pattern 的差异（如有）]
排除的混淆 Pattern：[检查过的易混淆 Pattern + 排除理由]
```

### 8.4 快速通道触发条件

满足以下条件时走快速通道：
- 匹配度 ≥ 中高
- 无自欺标记（X01 不匹配）
- 根因明确（不需要追问链）
- 无易混淆模式干扰

快速通道输出精简为：判断 + 2-3 个关键信号 + 下一步。
