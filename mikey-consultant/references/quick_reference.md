## 一、关系阶段速判

| 阶段 | 判断信号 | 核心任务 |
|------|----------|----------|
| 陌生 | 未建立联系/刚加微信 | 破冰、安全感 |
| 熟悉 | 有互动、无吸引信号 | 建吸引、适时邀约 |
| 暧昧 | 有IOI、互动升温 | 共振、试探窗口 |

| 长期 | 确定关系1月+ | 一致性、吸引力保鲜 |

## 二、六变量速判表

## 四、10 条核心原则一句话版

| ID | 原则 | 一句话 |
|----|------|--------|
| P01 | 关系动态决定吸引力 | 强不是数值，是姿态 |
| P02 | 潜沟通传递核心信息 | 状态大于内容，线索大于话语 |

| P08 | 边界感维持框架 | 敢拒绝=传递强线索 |
| P09 | 零压力状态最佳 | 不执着于结果反而更容易成功 |

## 六、常见误区速查

| 误区 | Mikey 体系观点 |
|------|----------------|
| 展示财富=吸引 | 只能让门当户对的坐下来喝杯咖啡，没吸引五分钟就跑 |
| 背话术=解决问题 | 状态先于内容，线索大于话语 |
| 对她好=获得回报 | 单向付出≠回报，可能降低吸引 |
| 赚更多钱=自信 | 价值≠价值感，真正的自信和这些无关 |
| 装就能维持 | 装了迟早会露馅，一致性断裂=下头 |
| 高开低走好 | 宁可低开高走也不要高开低走 |
| 升级只进不退 | 反感时必须坐回原点重新判断 |

## 七、决策模型一句话版

| 模型 | 核心判断 |
|------|----------|
| DM01 窗口判断 | 主动+单独见面=有窗口；被动+不提供话题=无窗口 |
| DM02 吸引力判断 | 有吸引→技术生效；无吸引→任何技术无效 |
| DM03 升级时机 | 有共振+身体开放→可升级；无共振升级=猥琐 |
| DM04 需求感判断 | 热度远高于对方=暴露需求感→对方停止投入 |
| DM05 框架位置 | 不敢反驳+没有原则=下位；敢于表达不同=上位 |
| DM06 邀约时机 | 有安全感→可邀约；推脱+假日也说忙=不想见你 |
| DM07 搭讪效果 | 不回复=现场问题或展示面问题 |
| DM08 长期健康度 | 行为前后不一致=吸引力开始下降 |
